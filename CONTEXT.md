## Состояние

Усреднённый трансформер трёх сидов, январское окно, 250k, gap-30. Числа
пересчитаны 20.08 против действующего пакета, подробности — `TRACK5_REPORT.md`:

```
сырой         скор 1.672635   r 0.99508   ЗАПАС +0.00118
калиброванный скор 1.670580   r 0.99570   ЗАПАС +0.00180
```

**Прежняя запись «r 0.99424, ЗАПАС +0.00205» не воспроизводится.** Скор верный,
расходится корреляция: фактическая 0.99508, для 0.00205 нужна была бы 0.99422.
Вероятно, считалось против более раннего пакета предсказаний. Рекорд проекта
по запасу — 0.00307 (`lagd28`, ось застоялости входа); прежние 0.00193 мерились
против более слабого бленда прошлой эпохи.

Но судить по запасу здесь нельзя, и это подтвердилось: формула «вклад ≈ 7.1·запас²»
**похоронена 20–21.08** — она откалибрована на слабых моделях (`sm/sb ≈ 1.06`) и для
трансформера (`sm/sb = 1.0025`) занижает в 15–20 раз. Действующая точная алгебра —
в `margin.py`; набор кандидатов мерить только `joint_gain.py`. Измеренный вклад
трансформера — 0.000465 при честной OOF-оценке, 20 шумовых единиц; это рекорд вклада
по проекту.

**На лидерборде модель дала −0.000184**: H1_applied 1.6489955 -> H2_tfm_half
1.6488111. Перенос валидации на тест составил 40%; причина — застоялость входа,
см. отчёт. Это единственная модель вне линейной оболочки бленда: из 31 модели
(30 в паке + эта) ненулевой запас только у неё.

Лучшая конфигурация (из суточного свипа, 90 испытаний):
`--lr 7e-4 --channels 192 --layers 4 --heads 4 --dropout 0.0 --wd 0.0122
--aux 0.25 --batch 512 --ema 0.995 --min-anchor 30`

## Две правки, ещё не прогнанные на полном масштабе

**Ранняя остановка по калиброванному скору.** Была по сырому — та же ошибка,
что нашёл Александр. Флаг `--es-metric cal`, включён по умолчанию. По его
замерам 0.0028 на сид и разброс между сидами падает в восемь раз.

**Когорта обучения по трём блокам.** Юниверс отобран как активный в каждом из
трёх 30-дневных блоков перед тестом — проверено, все 250000 удовлетворяют. Наш
фильтр требовал одного блока и пускал на 10–13% больше слабых юзеров, среди
которых вдвое больше молчащих. Правило применяется только к обучающим якорям,
валидация и выгрузка остаются на всех 250000. Запустить `make_valid3.py` один
раз, дальше работает по умолчанию, откат флагом `--cohort1`.

## Что закрыто измерениями. Не повторять

* **Гиперпараметры сети** — суточный свип, 90 испытаний: разброс 0.004 при шуме
  прогона 0.001. Ни один параметр не значим.
* **Размер модели** — 0.9 и 2.0 млн параметров дают одинаково.
* **Длительность обучения** — вчетверо больше шагов дало +0.0004, то есть ноль.
* **Диапазон якорей** — `min_anchor` 30/60/120/200 неразличимы.
* **Больше сидов** — корреляция между сидами 0.998, усреднение трёх дало −0.0017.
* **TCN** — вес 0.079 в ансамбле против трансформера, час GPU не окупает.
* **Стекинг** — трансформер проигрывает лучшей табличной модели во всех пяти
  сегментах по давности покупки, перераспределять веса по юзерам нечего.
* **Сырой недельный ряд признаками** — 1.6789 против 1.6796, ноль.
* **Календарная поправка по 2025 году** — мой расчёт дал +0.014, но он был
  неверен: сравнивались когорты разного размера. Правильный парный расчёт
  Александра даёт +0.188. Поправку меряют зондами лидерборда, не локально.

## Правила, за которые заплачено

1. Обучение только с зазором 30 дней между обучающими якорями и валидационным.
   Без него скор завышается на 0.05–0.1.
2. Сравнивать модели только ПОСЛЕ калибровки: `calibrate.py --pred ИМЯ --bins 24`,
   затем `err_corr.py ИМЯ_cal`, именно в таком порядке.
3. Валидационное окно слепо в левом хвосте — молчащих там нет по построению.
   Отрицательные результаты в области низких прогнозов проверять на зеркальном
   якоре 2025-10-15 (`--val-anchor 287`).
4. Приёмка идёт по ЗАПАСУ = `скор_бленда/скор_модели − корреляция_ошибок`
   (корреляция НЕцентрированная; сама по себе она ничего не значит — механически
   равна отношению скоров). Вклад считается точной алгеброй пары в `margin.py`,
   правило `7.1·запас²` похоронено. Набор кандидатов мерить только `joint_gain.py`:
   запасы не складываются. Эталон — колонка `blend` пакета `work/preds_pack`
   (1.665647), не константы из отчётов. Модель, чей прогноз есть функция 203
   табличных признаков команды, лежит в оболочке бленда и даёт ровно ноль.
5. Выгружаемые предсказания сырые, без поправки +0.17. Смешивать до наложения
   поправок, не после.
