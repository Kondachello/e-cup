# Прогон 2: три правки сразу

Что меняется относительно прогона от 18.08 (`RUN_TFM.md`):

1. **`--es-metric cal`** — ранняя остановка по калиброванному скору. В прошлый раз
   было по сырому. По замерам №1 это 0.0028 на сид.
2. **Когорта обучения по правилу трёх блоков** — включена по умолчанию, нужен
   один запуск `make_valid3.py`. Откат: `--cohort1`.
3. **Переобучение на train+val перед предсказанием теста.** Прошлые тестовые
   предсказания давала модель, обученная по якорь 348, тогда как остальные модели
   команды переобучены по 378 — зазор 60 против 30. Лидерборд это подтвердил:
   перенос валидации на тест составил всего 40% (обещано −0.000465, получено
   −0.000185).

Третья правка потребовала кода: раньше границу обучающих якорей нельзя было
задать отдельно от валидационного. Добавлены `--max-tr-anchor`, `--fixed-steps`,
`--cal-fixed`. Прогон с нарушенным зазором без `--fixed-steps` теперь падает
с явной ошибкой, чтобы такое нельзя было сделать случайно.

Почему нельзя просто поставить `--val-anchor 408`: таргет берётся из дней
`якорь+1..якорь+30`, а тензор кончается на дне 408. Максимальный валидный
валидационный якорь — 378.

## Ноль. Тензор

Тензор в `.gitignore` (2.6 ГБ), после чистого клона его нет. Варианта два.

**Если тензор уже собран** — просто указать на него:

```powershell
python work\scripts\seq\run_all.py --data C:\ozon\tensor
```

**Если нет** — раннер соберёт сам, нужен только `train.parquet`:

```powershell
python work\scripts\seq\run_all.py --data tensor --train-parquet C:\ozon\train.parquet
```

Сборка занимает около 12 минут и требует 2.6 ГБ на диске; раннер проверит место
заранее и сверит форму с ожидаемой 250000 x 409 x 10. `fix_gmv.py` при этом не
нужен — он чинит тензоры, собранные старой версией, где gmv писался в fp16.

Вручную то же самое:

```powershell
python work\scripts\seq\build_tensor.py --src train.parquet --out tensor
```

## Один. Маска когорты

```powershell
python work\scripts\seq\make_valid3.py --data tensor
```

Допишет маску `valid_anchor3` в `tensor/meta.npz`, сам тензор не тронет.
Раннер делает это сам, если маски ещё нет.

## Фаза A — измерение, зазор 30 дней

Отсюда берутся `_val.parquet` для сравнения моделей, а также **число шагов** и
**усадка** для фазы B. Три сида:

```powershell
python work\scripts\seq\train_tcn.py --data tensor --arch transformer --minutes 55 `
  --lr 7e-4 --channels 192 --layers 4 --heads 4 --dropout 0.0 --wd 0.0122 `
  --aux 0.25 --batch 512 --ema 0.995 --min-anchor 30 `
  --val-users 0 --val-anchor 378 --es-metric cal `
  --seed 1 --tag tfm2_s1 --export work\preds
```

плюс `--seed 2 --tag tfm2_s2` и `--seed 3 --tag tfm2_s3`.

`--predict` здесь НЕ нужен: тестовые предсказания даст фаза B, а инференс теста
стоит несколько минут на прогон.

В конце каждого прогона выписать две строки из лога:

```
ЛУЧШЕЕ val RMSLE ... на шаге NNNN        <- это N_A для фазы B
выбрана усадка C -> val RMSLE ...        <- это C для фазы B
```

## Фаза B — переобучение по якорь 378, только тест

Число шагов масштабируется по числу обучающих срезов: фаза A видит якоря
30..348 (319 штук), фаза B — 30..378 (349), отношение **1.094**. То есть
`--fixed-steps = round(N_A × 1.09)`.

```powershell
python work\scripts\seq\train_tcn.py --data tensor --arch transformer `
  --lr 7e-4 --channels 192 --layers 4 --heads 4 --dropout 0.0 --wd 0.0122 `
  --aux 0.25 --batch 512 --ema 0.995 --min-anchor 30 `
  --val-users 0 --val-anchor 378 --max-tr-anchor 378 `
  --fixed-steps <N_A*1.09> --cal-fixed <C> `
  --seed 1 --tag tfm2_s1_rt --export work\preds --predict FILE.csv
```

плюс сиды 2 и 3 со своими `N_A`, `C` и тегами.

**Важно.** Фаза B тоже выгрузит `tfm2_sN_rt_val.parquet` — этот файл использовать
НЕЛЬЗЯ, у него нарушен зазор и скор завышен. Нужен только
`tfm2_sN_rt_test.parquet`. Поэтому теги разные: `_val` из фазы A не затирается.

Скрипт сам напечатает предупреждение про зазор — так и должно быть.

## Чего ожидать

Если правки дадут заявленные планом 0.0028 на сид, вклад в бленд на валидации
вырастет с 0.00046 до примерно 0.0017. При нынешнем переносе 40% это дало бы
0.0007 на лидерборде; если переобучение по 378 починит и перенос, то больше.
Разрыв до топ-1 сейчас 0.0021 (наш 1.6488111 против 1.64586).

Оценка оптимистичная: она держит корреляцию ошибок постоянной, а более сильная
модель обычно сильнее коррелирует с блендом.
