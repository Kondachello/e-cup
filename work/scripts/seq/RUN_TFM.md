# Прогон трансформера для командного ансамбля

Конфигурация взята из суточного свипа (`final3` — лучшая на полной длине).
Экспорт сразу в формате `work/preds/` тиммейта: `user_id, pred` в сыром
масштабе GMV, как требует его `exp_lib`.

## Основное окно (2026-01-14), три сида — с тестовыми предсказаниями

```powershell
python train_tcn.py --data tensor --arch transformer --minutes 55 `
  --lr 7e-4 --channels 192 --layers 4 --heads 4 --dropout 0.0 --wd 0.0122 `
  --aux 0.25 --batch 512 --ema 0.995 --min-anchor 30 `
  --val-users 0 --val-anchor 378 `
  --seed 1 --tag tfm_s1 --export work/preds --predict FILE.csv
```


## Второе окно (2025-12-31), три сида — только валидация

Это окно нужно его протоколу отбора: январь один ранжирует модели неверно
из-за новогоднего спада. Тестовые предсказания отсюда не нужны, `--predict`
не указываем — экономит несколько минут инференса.

```powershell
python train_tcn.py --data tensor --arch transformer --minutes 55 `
  --lr 7e-4 --channels 192 --layers 4 --heads 4 --dropout 0.0 --wd 0.0122 `
  --aux 0.25 --batch 512 --ema 0.995 --min-anchor 30 `
  --val-users 0 --val-anchor 364 `
  --seed 1 --tag tfm_dec_s1 --export work/preds
```

плюс `--seed 2 --tag tfm_dec_s2`, `--seed 3 --tag tfm_dec_s3`.

Итого шесть прогонов по 55 минут.

## Что получится

```
work/preds/tfm_s1_val.parquet     предсказания на 250k, якорь 2026-01-14
work/preds/tfm_s1_test.parquet    предсказания на 250k, якорь 2026-02-13
work/preds/tfm_dec_s1_val.parquet предсказания на 250k, якорь 2025-12-31
FILE.csv                    сабмит-формат, если понадобится отдельно
FILE.csv.logpred.npy        логиты для ковариационной алгебры
```

Файлы `*_val.parquet` и `*_test.parquet` кладутся прямо в его библиотеку —
`caruana.py` подхватит их автоматически, он сканирует `work/preds/*_val.parquet`
с парным `*_test.parquet`.

## Дисциплина зазора

`--val-anchor` теперь задаёт и границу обучающих якорей: `MAX_TR_ANCHOR =
val_anchor − 30`. Для якоря 378 обучение идёт по 348 (2025-12-15), для 364 —
по 334 (2025-12-01). Это тот же `gap30`, что у него, так что валидационные
числа сопоставимы напрямую.

Индексы дней считаются от 2025-01-01: **378 = 2026-01-14**, **364 = 2025-12-31**,
408 = 2026-02-13 (тест).

## Оговорка про тестовые предсказания

Модель для теста — та же, что валидировалась, то есть обученная по якорь 348.
Формально его контракт требует переобучения на train+val (якоря до 378).
Мы этого не делаем сознательно: свип показал, что диапазон якорей вообще не
влияет на результат (`min_anchor` 30/60/120/200 дали одинаковую медиану), а
переобучение стоило бы ещё трёх часов GPU.

## Чего ожидать

По замеру на воспроизведённой подвыборке поправка между 40k и полными 250k
составляет +0.0018, так что прежние 1.6755 на подвыборке соответствуют
примерно **1.674** на его шкале. Это уровень его лучшей одиночной модели
(`mlp2_final_cal` 1.6726) и на 0.037 лучше его `seq2tr_f`.

Главная ценность не в этом, а в корреляции: у него все сильные модели
скоррелированы на r=0.995 (его же факт Ф20), потому что построены на одних
табличных признаках. Трансформер по сырым последовательностям в эту связку
не входит — именно это даёт вес в отборе Каруаны.
