# kevf3: ось закрыта замером — следствия для всех треков (29.08)

Отчёт исполнителя принят. Итог: механизм со-обучения РАБОТАЕТ (+0.0055 к базе,
tabzero цел, коллапса нет), но как член бленда — шум (вклады +7e-6/+1.1e-5 при
пороге 4.4e-5, корреляция с блендом 0.9978). Причина диагностирована: ТАБЛИЦА
В БЛЕНДЕ НАСЫЩЕНА — любая модель, читающая те же 176 признаков, приходит к
corr≈0.998 независимо от архитектуры ствола.

## В доктрину (и в монографию K3)

**Резерв новых членов — только TABLELESS.** Два независимых подтверждения за
сутки: (а) kevf3 с таблицей = шум при отличном соло; (б) ktpp Кости БЕЗ таблицы
= +0.00006 «не шум» при соло всего 1.671; (в) исторический рекорд запаса —
tfm4_tabless (corr 0.982, единственный ниже 0.985). Ценность даёт член, который
таблицу принципиально НЕ видит.
