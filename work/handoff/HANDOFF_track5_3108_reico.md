# ЗАДАЧА B. Остаток КОМБИНАЦИИ, а не отдельной модели

Обметание закрывало модели **поодиночке**: tabless 1.001, tfm4 0.819, kevf 0.334,
ktpp −2.576. Все применены.

Но вот чего никто не смотрел. Цепочка прошла по каждому направлению отдельно —
значит ли это, что она прошла по **их комбинации**? Геометрически нет: у двух-трёх
направлений может быть общая компонента, ортогональная всему, что применено, и
которой нет ни у одного из них по отдельности.

У тебя на диске лежат выходы, которых нет у меня: `tfm3`, `tfm3b`, `tfm4`,
`tfm4_tabless`, `kevf_tl_gru` всех сидов, `fusion_v3_avg`. Проверь:

```
corr   = lp(submissions/F12_ebint.csv) − blend_test         # применённая поправка
D      = матрица применённых направлений (сколько есть на диске)
для набора моделей M: строим их общую компоненту, вычитаем проекцию на span(D),
считаем q остатка и сравниваем с q каждой модели по отдельности
```

Если у комбинации остаток заметно больше, чем у любого её члена, — это живая ось, и
на неё у нас есть посылка. Если нет — семейство закрыто окончательно, и это тоже
результат, который надо записать.

Инструмент — `work/scripts/axis_applied.py`, читай докстринг целиком, там объяснён
контроль по 200 случайным направлениям той же нормы. **Без этого контроля число не
значит ничего.**
