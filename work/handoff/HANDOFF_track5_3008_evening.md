## A2. Фоном на ночь — прогон из `CONTEXT.md`, три правки разом

Ставите сейчас, оно крутится само, смотрим утром. Ваше внимание оно не занимает.

```
python work\scripts\seq\run_all.py --data <папка тензора>
```

Три правки: `--es-metric cal` (ранняя остановка по калиброванному скору, 0.0028 на
сид и разброс между сидами в восемь раз меньше), когорта трёх блоков, переобучение на
train+val перед предсказанием теста.

**Почему это не «ещё одна модель».** Меняется не архитектура, а **процедура отбора
якорей и критерий остановки**. По доктрине штаба платят именно свойства постановки, а
не модели: обе крупнейшие находки проекта (критерий ранней остановки, отбор
пользователей по трём блокам) — ровно этого класса, и обе стоили больше всего перебора
гиперпараметров вместе взятого.

Результат проверять **через `axis_applied.py`, а не через `joint_gain`**: joint_gain
меряет прирост к неисправленному бленду и про цепочку из 46 поправок не знает.
