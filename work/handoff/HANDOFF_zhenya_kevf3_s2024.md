# Жене — довесок к K: третий сид kevf3 (s2024) на твоей карте

Передаю тебе ногу, которая молчала у трека 5: **kevf3, сид 2024, 12000 шагов,
локально**. Она фоновая — карта считает, пока ты пишешь K2/K3, руки нужны
на 15 минут постановки.

## Что взять

1. `work/kaggle/kaggle_seq.py` — версия v3 из ветки sasha (TabStore, --tab,
   --warm-from; при выключенных флагах побитово v2).
2. Табличные матрицы: `work/data/kaggle_session3/kaggle_feats/` (26 npz +
   tabf16_meta.json) — уже в репо-дереве у Саши; если у тебя их нет, они
   регенерируются `work/scripts/export_anchor_feats.py --grid wed` (~30 мин CPU).
3. Тёплая база: `ozon_kevf_ckpt.zip` в корне репо → распакуй, нужен
   `kevf_v2.ckpt` + `kevf_v2.json` (двое других гонят v2-s42 и gru-s1337,
   твоя комбинация v2-s2024 даёт третью точку диверсификации).
4. `train.parquet` из корня репо.

## Запуск (адаптация ячеек NOTEBOOK_JF.md под локаль)

```
python kaggle_seq.py build --gap 35          # стор на сетке сред, ~2-5 мин GPU-машины
python kaggle_seq.py train --name kevf3_s2024 --seed 2024 --device cuda:0 \
    --tab <путь к kaggle_feats> --tab-mode concat --tab-dropout 0.15 \
    --warm-from <путь>/kevf_v2.ckpt --lr 2e-4 --max-steps 12000
```

Пути данных скрипт ищет сам (см. шапку kaggle_seq.py — если локальная
раскладка не подхватится, там один env/аргумент). Арх-флаги при v2-базе —
дефолтные (cfg в kevf_v2.json это подтверждает; сверь глазами).

Контроль первых минут: в логе должны появиться «таблица: (26, 250000, 176)»,
«--warm-from: скопировано … тензоров», «warm-старт OK». Дальше каждый eval
печатает пару «скор | tabzero»: tabzero ~1.67 — норма; развал tabzero при
скоре уровня табличных — коллапс, перезапуск с --tab-dropout 0.4.

`out/kevf3_s2024_{val,test}.parquet` + `kevf3_s2024.json` в `work/colab/out/`
