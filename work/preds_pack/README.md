# Валидационная и тестовая матрицы прогнозов

Два файла на 250 000 строк, отсортированы по `user_id`, значения — **логарифмы**
прогнозов (`log1p`), потому что метрика живёт в логарифмах.

- `val_preds.parquet` — окно 15.01–13.02.2026 (якорь валидации 2026-01-14). Есть
  колонка `target` — сырой GMV, не логарифм.
- `test_preds.parquet` — окно 14.02–15.03.2026. Те же колонки, кроме `target`.

Колонка `blend` — действующий бленд: её скор на валидации **1.665647**, ровно то
число, что указано в `final_submission/README.md` §4 и в `reproduce_training.md` §5.
Оно и служит эталоном во всех измерениях приёмки.

Дальше идут 14 колонок членов бленда (имена совпадают с ключами `BLEND_WEIGHTS` в
`final_submission/inference.py`) и несколько опорных: сырые, некалиброванные версии
трёх внешних членов (`kostya46`, `gseq_small_s42`, `gseq_big_s42`) и калиброванные
прогнозы моделей, в действующий состав не вошедших, — они оставлены как опора для
сравнения, весов в бленде у них нет.

Пересобирается скриптом `work/scripts/build_preds_pack.py` из `work/preds/`.

## Зачем эти файлы нужны инструментам

Три скрипта читают `val_preds.parquet` напрямую и без него не работают:

| скрипт | что делает |
|---|---|
| `work/scripts/margin.py` | считает ЗАПАС модели — долю её прогноза вне линейной оболочки бленда — и вклад в бленд |
| `work/scripts/err_corr.py` | корреляция ошибок с блендом, шаг приёмки после калибровки |
| `work/scripts/retrain_table.py` | подставляет переобученного члена в бленд НА ЕГО ЖЕ ВЕС и меряет сдвиг; из него таблица §7 в `final_submission/README.md` |

## Правила измерений, которыми пользовались

- **Сравнивать модели только после калибровки.** По сырым скорам модели систематически
  меняются местами: сырой порядок обманывал восемь раз. Калибровка — поквантильный
  сдвиг в логарифмах с честным разрезом (половина пользователей подбирает сдвиги,
  вторая ими правится, и наоборот), `work/scripts/calibrate.py`.
- **Корреляция ошибок сама по себе ничего не значит.** Для модели внутри линейной
  оболочки бленда она тождественно равна `sb/sm`, то есть определяется её же скором.
  Проверено до пятого знака на 101 модели. Значение имеет только запас `z = sb/sm − ρ`.
- **Зазор 30 дней** между обучающими срезами и валидационным окном обязателен: без него
  целевые окна пересекаются и скор завышается примерно на 0.1.
- **Плацебо.** Добавление четырёх произвольных существующих моделей в бленд само по
  себе даёт +0.00011; прирост сравнивать с этим уровнем.
