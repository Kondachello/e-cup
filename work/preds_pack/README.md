# Набор предсказаний для опытов

Два файла на 250 000 строк, отсортированы по `user_id`, значения — **логарифмы**
прогнозов (`log1p`), потому что метрика живёт в логарифмах и все расчёты удобнее
вести прямо в них.

- `val_preds.parquet` — окно 15.01–13.02.2026. Есть колонка `target` (сырой GMV,
  не логарифм) и колонка `blend` — наш действующий бленд.
- `test_preds.parquet` — окно 14.02–15.03.2026. Те же колонки, кроме `target`.

Всего 30 моделей: 22 члена бленда и 8 опорных. Пересобирается скриптом
`work/scripts/build_preds_pack.py`.

Модели эпохи до введения зазора 30 дней (`gru_final`, `lgblog_final`, `xgblog_final`,
`mlp_final`) в пак не входят: их валидационный скор завышен на 0.05–0.10, и любые
выводы по ним будут неверными.

## Как проверить свою модель за минуту

Главный вопрос про новую модель — не её скор, а **запас**: доля модели вне линейной
оболочки бленда. Вклад в общий результат равен примерно `7.1 · запас²`.

```python
import numpy as np, polars as pl

d = pl.read_parquet("val_preds.parquet").sort("user_id")
y = np.log1p(d["target"].to_numpy().astype(float))
b = d["blend"].to_numpy().astype(float)          # уже log1p

# ваши прогнозы на том же окне, в том же порядке user_id, сырой GMV
mine = np.log1p(np.clip(my_predictions, 0, None))

sb = np.sqrt(((y - b) ** 2).mean())              # скор бленда
sm = np.sqrt(((y - mine) ** 2).mean())           # скор вашей модели
rho = np.corrcoef(y - b, y - mine)[0, 1]         # корреляция ошибок

margin = sb / sm - rho
print(f"скор {sm:.6f}  корреляция {rho:.5f}  ЗАПАС {margin:+.5f}  "
      f"ожидаемый вклад {7.1 * margin**2:.6f}")
```

Что означают числа:

- **корреляция ошибок сама по себе ничего не значит.** Для модели внутри оболочки она
  тождественно равна `sb/sm`, то есть определяется вашим скором. Проверено до пятого
  знака на 101 модели. Прежний критерий «ищи корреляцию ниже 0.97» был пустым.
- **работает только запас.** Рекорд за всё время проекта — 0.00193. Чтобы дать прирост
  0.0003 (наш порог осмысленности), нужен запас 0.0065.
- уровень шума одного замера на лидерборде — 0.000022. Прирост меньше двух таких
  единиц неотличим от шума.

## Обязательно: калибруйте перед сравнением

Сравнивать модели по сырому скору нельзя — за время проекта такое сравнение обмануло
нас **восемь раз**, в том числе дважды за одну ночь подряд. Калибровка — поквантильный
сдвиг в логарифмах, с честным разрезом, чтобы сдвиги подбирались не на тех же строках,
на которых меряются:

```python
def fit_shifts(lp, ly, bins=24):
    """Средний сдвиг логарифма внутри квантильных бинов. Бины меньше 500 строк
    пропускаются: сдвиг по ним слишком шумный."""
    qs = np.quantile(lp, np.linspace(0, 1, bins + 1))
    qs[0] -= 1e-9; qs[-1] += 1e-9
    centers, shifts = [], []
    for i in range(bins):
        m = (lp > qs[i]) & (lp <= qs[i + 1])
        if m.sum() < 500:
            continue
        centers.append(lp[m].mean())
        shifts.append(ly[m].mean() - lp[m].mean())
    return np.array(centers), np.array(shifts)


def calibrate_honest(lp, ly, bins=24, seed=0):
    """Половина пользователей подбирает сдвиги, вторая ими правится, и наоборот.
    Так сдвиги никогда не меряются на тех же строках, на которых подобраны."""
    rng = np.random.default_rng(seed)
    half = rng.permutation(len(ly)) < len(ly) // 2
    out = np.empty_like(lp)
    for m in (half, ~half):
        c, s = fit_shifts(lp[m], ly[m], bins)
        out[~m] = np.clip(lp[~m] + np.interp(lp[~m], c, s), 0, None)
    return out
```

Считайте и скор, и запас **по калиброванным** прогнозам. Колонка `blend` в паке уже
собрана из калиброванных членов.

## Что ещё стоит знать, прежде чем что-то запускать

- Обучение только с зазором 30 дней между обучающими срезами и валидационным окном.
  Без зазора целевые окна пересекаются и скор завышается примерно на 0.1.
- Новый набор признаков сравнивайте с контролем **равной ёмкости** — добавьте столько
  же старых признаков. Так у нас развалились три тира подряд.
- Смоуки на 200 шагах ранжируют конфигурации **обратно** полному масштабу. Годятся
  только для проверки, что код работает.
- Любой прирост сравнивайте с плацебо: добавление четырёх произвольных существующих
  моделей в бленд само по себе даёт +0.00011.
