# Пакет предсказаний (для тиммейтов)

Два файла вместо 137: только модели, обученные по проверенному протоколу.

- `val_preds.parquet` — 250 000 строк: `user_id`, `target` (факт за 15.01–13.02.2026) и по колонке на модель
- `test_preds.parquet` — те же модели на тестовом окне (14.02–15.03.2026), `target` неизвестен

Порядок строк совпадает с `sample_submit.csv` (отсортирован по `user_id`).

Некалиброванные версии нейросетей (`mlpbin`, `mlpziln`, `mlp2_big`) тоже включены —
калибровка это поквантильный сдвиг в log-пространстве, подобранный на валидации.

## Важно про подбор весов

Смешивайте **в log1p-пространстве**: `pred = expm1(sum_i w_i * log1p(pred_i))`.
Веса подбирайте на `val_preds.parquet` по RMSLE, затем применяйте к `test_preds.parquet`.

Учтите: у сильных моделей корреляция ошибок 0.995+, поэтому смешивание даёт очень мало.
Реальный выигрыш у нас пришёл от непохожих компонент (febspec — корреляция 0.91,
seq2tr_f — 0.987) и от замеров смещений через лидерборд, см. `work/reports/probe_plan_v2.md`.

## Пример

```python
import numpy as np, polars as pl
v = pl.read_parquet("val_preds.parquet")
y = np.log1p(v["target"].to_numpy())
lp = {c: np.log1p(np.clip(v[c].to_numpy(), 0, None)) for c in v.columns if c not in ("user_id","target")}
rmsle = lambda l: float(np.sqrt(np.mean((l - y)**2)))
print("лучшая одиночная:", min((rmsle(l), c) for c, l in lp.items()))
```
