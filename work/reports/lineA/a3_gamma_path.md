## 1. Что такое «вершина параболы» — и почему пришлось её определить точно

Своя парабола оси *i* по **полной** дозе `b`:

```
G_i(b) = −q_i·(b − v_i)² + const,        v_i = b_i^F7 + c_Q,i / q_i
```

`v_i` — вершина: доза, оптимальная для оси, если смотреть только на неё.
`b = 2·v_i` — точка, где собственный вклад оси возвращается к нулю (то же, что «не дозировать
её вовсе»). Отсюда правило (б) в проверяемом виде:

```
r_i = b_i / v_i ∈ [0, 2]      (r < 0 = доза по другую сторону нуля от вершины — та же беда)
```

Честная вершина mdl_olivin на состоянии F7 = 1.367 при дозе 1.431, то есть ось стоит
**практически в вершине** (r = 1.05), а не в 17 вершинах. Все числа ниже — по `v_i`.

Цена перелёта считается в шумах, по собственной параболе, против нулевой дозы:

```
цена_i = q_i·[(b_i − v_i)² − v_i²] / (2·F_SCALE·NOISE)      [шумов LB]
```

Она положительна ровно тогда, когда `r_i ∉ [0,2]`, и меряет то, что предлагал мерить
Женя в П.2 («смотреть надо на `b·q`, а не на `b`»).

## 3. ГЛАВНОЕ ДЛЯ ПОДПИСИ: правило (б) в буквальном виде невыполнимо

Формулировка задания — «ни одна доза не превышает 2x вершины своей параболы» — **не
выполняется ни при каком γ**, и это не свойство пути, а свойство базы:

Гребень на это влияет слабо: при γ → ∞ дозы
  сходятся к дозам F7, и нарушения остаются.
* Действующий, подписанный F8 нарушает её на **12–14 осях** (в зависимости от судьи). Отношение взрывается там, где вершина
  численно около нуля, а не там, где есть риск.

Вывод: **отношение `доза/вершина` без фильтра материальности — не метрика риска, а деление
на ноль.** Это ровно то возражение, которое Женя уже занёс в доктрину в П.2 подписи F8
(«смотреть надо на `b·q`, а не на `b`»). Правило (б) надо либо переформулировать, либо
считать неприменимым.

**Предлагаемая формулировка (прошу утвердить):**

> (б′) Ни одна ось не должна стоить на **своей** параболе больше **1 шума** относительно
> нулевой дозы: `q_i·[(b_i − v_i)² − v_i²] / (2·F·NOISE) ≤ 1`.
