## 2. Почему буква задания не может дать заявленную массу

Для **контраста** (±1: верхняя половина вверх, нижняя вниз, остальные 0) при
конвенции семейства STEP = 0.30

```
q = STEP² · m  (m — масса ВСЕГО разрезаемого сегмента; дисбаланс половин почти не влияет)
```

— и это ровно тот выигрыш, ради которого штаб придумал сплит: контраст щупает
**всю** массу сегмента, а не тонкий хвост. Но:

```
спящие 91–365:  m = 0.1172  →  q = 0.0105    (заявлено 0.019…0.0225)
```

Заявленный коридор `q ≈ 0.019–0.0225` достижим только при `m ≈ 0.21–0.25`.
Такую массу даёт либо «спящие + никогда-не-покупавшие» (m = 0.2449 → q = 0.0220,
ровно верх коридора — похоже, штаб считал именно так), либо расширение окна
давности до `rec ≥ 46`. **Внутри 91–365 нужной массы нет.**
