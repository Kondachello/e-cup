## 1. Что такое «локальная g» оси и где она считается


```
H  = D * r                                   # h_i · r поюзерно, r = вал-остаток
Hc = H - H.mean(1, keepdims=True)
g_vec = sqrt(mean(Hc²)) / (F0v * sqrt(q))    # <-- локальная g
C_val = (Hc @ Hc.T) / n
```

где `r = log1p(target_val) − log1p(pred_val)` — остаток бленда на вале,
`F0v = sqrt(mean(r²)) = 1.6646919` (RMSLE бленда на вале), `q_i = mean(d_i²)` —
норма unit-направления оси.

**Смысл.** Закон Жени (часть C, 23.08) в исходном виде брал σ_κ = F0/√(n·q), т.е.
неявно допускал `g = 1` — что произведение `d_i·r` по юзерам имеет sd ровно
`F0v·√q_i` (как если бы `d` и `r` были независимы и `r` — гомоскедастичный).
Локальная g снимает это допущение: она измеряет, во сколько раз реальный разброс
`d_i·r` больше/меньше гомоскедастичного. Отсюда **поосная** ошибка замера каппы:

```
σ_i = g_i · F0_base(i) · sqrt(0.8 / (50000 · q_i))        # строка 192
```

0.8 = fpc (50k публики из 250k), F0_base — паблик-скор базы оси. **g строится
ТОЛЬКО из валидации**, паблик в неё не входит (это важно для §5).

Замер каппы (`κ_pair`, строки 154–187) — параболический, из ДВУХ ПУБЛИЧНЫХ
скоров (база + зонд) с поправкой на уровень `c1`:

```
c_step = (S_base² − S_probe² + q_step) / 2
c_d    = (c_step − mean(step)·c1(base)) / b_probe
κ_i    = c_d / q_i
```

Приор `κ_i ~ N(μ_fam, τ_fam²)` и усадка `w = τ²/(τ²+σ_i²)` — это и есть место,
где живёт `PRIOR_MODEL` (строка 51). τ входит дважды: в `Sig_p = diag((q·τ)²)`
(калмановский коэффициент K → апостериор m*) и в демпфер
`Lam = q(1−w)τ²`.

## 5. КОНТРОЛЬ ЧЕСТНОСТИ: утечки паблика в оценку τ нет

Проверено по коду, а не на слово. Разбираю честно, включая ту часть, которая
в формулировке задания сформулирована неточно.

**5.1. Что говорит формулировка задания:** «tau оценивается по валидационным g,
а не по публичным замерам». **Это верно наполовину, и вторую половину надо
назвать вслух:**

* `σ_i` (локальная g) — **чистая валидация**: `r` — вал-остаток, `D` — направления,
  `F0v` — вал-RMSLE. Паблика в σ нет вообще.
* `κ̂_i` — **это публичные замеры зондов** (два скора с платформы на ось).
  τ оценивается по разбросу κ̂ относительно σ, значит публичные замеры в оценку
  входят.

**5.2. Почему это всё равно НЕ подгонка паблика.** Запрет доктрины (директива
23.08, `no-public-fitting`) — про выбор доз, минимизирующих ПУБЛИЧНЫЙ СКОР
кандидата. Здесь:

* Замер **F8_priv = 1.6458057389 в оценку τ не входит вообще.** Проверено:
  `S_names` солвера (стр. 76–82) не содержит F8; базы EXTRA-точек — T3 и V3. Единственное место,
  где F8-замер вообще может всплыть, — `plb.load_basis()` в информационной печати
  `predict_lb` (строки 485–491), и она выполняется **после** того, как вектор доз
  `dstar` уже вычислен. Обратной связи нет.
* τ — это **гиперпараметр приора на ПРИВАТНУЮ κ**, а зондовые κ̂ — санкционированный
  канал наблюдения, за который уже заплачено попытками. Весь GLS построен на них;
  запретить их в оценке τ означало бы запретить и сам GLS.
* Никакой перебор по публичному скору не производился: τ взята как оптимум
  маргинального правдоподобия по (κ̂, σ), с ДИ и LOO.

**5.3. Структурная связь, которую обязан назвать (это не утечка, но риск).**
Паблик-алгебра кандидата **монотонно улучшается с ростом τ**:

| τ | 0.196 | 0.2625 | 0.2855 | 0.2975 | 0.35 |
|---|---|---|---|---|---|
| паблик-алгебра | 1.6457652 | 1.6456979 | **1.6456836** | 1.6456773 | 1.6456570 |

Причина понятна: больше τ → меньше усадка → дозы ближе к публично замеренным κ̂
→ лучше публичный скор. **Фальсификация**: если бы мы подгоняли паблик, мы бы
взяли τ → ∞ (это предел w→1, паблик продолжает падать). Мы взяли 0.2855 —
оптимум правдоподобия, который лежит далеко от «публично-оптимального» края.
Но правило для штаба из этого следует жёсткое: **любая будущая правка τ вверх
обязана проходить тот же тест — ДИ, LOO, чувствительность — иначе «улучшение
паблика» будет её единственным основанием, а это уже запрещённая подгонка.**

**5.4. Остаточная оговорка (не решена, честно).** Набор из 19 осей — это те оси,
которые *дошли до зонда*. Отбор «какую ось вообще зондировать» делался по
вал-свидетельствам, поэтому μ (центр) может быть завышен относительно «всех
мыслимых модельных осей». На τ этот отбор влияет слабее (он сжимает набор по
ожидаемому эффекту, а не по реализованному), но полностью его исключить нельзя.

## 8. Вердикт и что делать

**НЕ ТРАТИТЬ СЛОТ НА F9.** +0.43 шума против правила траты «≥10 шумов для
немедленного замера, 3–10 в батч» — не проходит даже нижнюю планку батча в 3 шума.
Ожидание кампании по линии A было «+0.0002…0.0004» (9–18 шумов); фактический
карман **в 20–40 раз меньше**. Причина не в τ, а в геометрии: квадратичная цель
GLS вблизи оптимума плоская, а γ=0.1 уже демпфирует; сдвиг оптимума на
||Δ||=0.36 в пространстве 46 доз стоит ~1e-5 на скор.

**ЧТО ПРИНЯТЬ (это и есть настоящий результат A1):**

1. **τ_model = 0.2855 (μ = 0.3076)** — новый приор модельного семейства для
   ВСЕХ будущих расчётов. Реестровое 0.196 занижено в 1.46 раза из-за отбора
   по исходу. Записать в реестр и в `PRIOR_MODEL` при следующей ЗАКОННОЙ
   пересборке (не ради самого приора, а когда пересборка идёт по другой
   причине — например с новой осью).
2. **Там, где τ действительно платит, — это слепые дозы новых осей.**
   Для оси с σ ≈ 0.23 (типичный зонд полным шагом, как mdl_wulfen/ktpp/kevf-tabless)
   вес замера растёт 0.42 → 0.60. Слепая доза без зонда остаётся 0.309 (μ
   подтверждён), но **постериорная доза после зонда** меняется заметно:
   `доза = 0.3076 + 0.60·(κ̂ − 0.3076)` вместо `0.309 + 0.42·(κ̂ − 0.309)`.
   Это прямо касается гейтов линий B (kevf-TABLESS) и C (ktpp).
3. **Для A3 (пересчёт γ):** ridge-путь под новым приором в §6; при равном γ
   решение менее экстремально, max|Δb| падает 0.787 → 0.658.
4. **Для A2 (аудит осей с w_p<0.10):** новый приор сам снимает часть переусадки
   и тянет mdl_gneis2 с 2.08 к 1.86; вершина параболы mdl_gneis2 = 1.32 всё ещё далеко.
5. Отдельного слота он не стоит.

**Оговорки, которые нельзя терять:**

* 19 точек — мало. 95% ДИ [0.172, 0.463] **включает реестровое 0.196**. Правка
  доказана по точечной оценке и по механизму (§4), но не по значимости.
* Гипотеза штаба τ≈0.35 не подтверждена; 0.35 — верхняя треть ДИ.
* κ̂ строятся из публичных замеров зондов (§5.1). Утечки замера F8 нет, подгонки

  будущая правка τ вверх проходила ту же проверку.
  вывод от него не зависит.
* Все прогоны — локальные, LB не тронут, ни один файл в `submissions/` не
