## 4. Часть C: закон σ_κ (главный технический результат)

Формула из реестра `σ_κ = шум_LB·(F0+S)/(2q)` пропускает шум **скора** через
параболу. Но публичный скор точен. Неопределённость κ в том, что `c` меряется
на выборке 50 000, а применять надо ко всему тесту.

Решающий замер (оси с заданным q, нарезка 50k, 300 розыгрышей):

| q | эмпирика | мой закон | параболическая | занижена в |
|---|---|---|---|---|
| 0.00066 | 0.2518 | 0.2901 | 0.0556 | 4.5 |
| 0.00229 | 0.1265 | 0.1555 | 0.0160 | 8 |
| 0.02000 | 0.0503 | 0.0527 | 0.0018 | 28 |

Причина: у параболической `σ ∝ 1/q`, у истинной `σ ∝ 1/√q`.

```
σ_κ = F0 / sqrt(n_публики · q)
```

### Дозирование

REML на 15 осях: **τ = 0.2039** — совпадает с исходной оценкой 0.205. LOO:
побеждает **плоский приор** N(0.333, 0.205²) (−0.4690) против гибрида (−0.5661),
синтеза (−0.6389), иерархии (−0.7732).

```
w = τ²/(τ² + σ_κ²),  τ² = 0.0416
```
Перелом w=0.5 при **q = 0.00134**. Ось с q<0.0замерять бессмысленно.
Однороден только бленд-класс (разброс 0.051 при шуме 0.210).

### Налог на приват

```
налог одной оси без усадки = F0·(1/n_pub + 1/n_priv)/2 = 0.0000208
```
Не зависит от q. Сумма по 15 осям: **3.5 шума с усадкой, 14.2 без.**

Следствия: налог **не уменьшается** повторным замером той же оси (скор
детерминирован) — одна проба на ось. Уменьшается только увеличением q.
