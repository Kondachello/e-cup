# Могильник: hull-probe заново об ТЕКУЩИЙ бленд (22.08) — ТЕОРЕМА ПОДТВЕРЖДЕНА

**Вопрос.** Теорема оболочки («остаток бленда не выводится из признаков») доказывалась
об старые бленды: H1 LGB-стек OOF R²=−0.019 (c_cand, 1.6717), TabPFN на 4к строк
(−0.0116 при плацебо −0.0011). Состав радикально сменился (kostya46_cal 0.246 +
tfm3b 0.20 + gseq + lagd28; эталон — колонка `blend` пака, замерено 1.6656470).
Мог ли остаток НОВОЙ эпохи приобрести структуру? Критерий задачи: OOF R² > +0.002 —
оболочка прохудилась; ≤ 0 — теорема подтверждена.

**Постановка.** Полные 250к юзеров (пак = 1 строка на юзера), остаток
r = log1p(y) − blend. LGB-стек OOF по юзерам, 5 фолдов (perm(seed 0) % 5, те же фолды
во всех вариантах), лёгкие параметры (350 деревьев, lr 0.08, nl 63, mcs 500,
ff/bf 0.8, max_bin 127, 2 потока). Признаки: 196 (USE_V2=1 USE_V3=1, якорь
2026-01-14) и отдельно 117 safe-колонок (не задетых обрезкой MAX_BACK=379 — на
тестовом якоре их вход не искажён). Плацебо — тот же конвейер на остатке,
перемешанном между юзерами. Опора — ridge на тех же фолдах (протокол
exp_resid_ridge). Выигрыш = sb − score(blend + oof). Скрипт
`work/reports/grave_hull_probe.py`, сырые числа `grave_hull_probe.json`, 534 с.

## Вывод: МЁРТВ ПОВТОРНО, линейка «стек» закрыта окончательно

1. **Best real LGB R² = −0.0111 ≤ 0 при пороге +0.002** — остаток текущей эпохи
   так же невыводим из 203/196 признаков нелинейной моделью, как и остаток старой.
   Три независимых замера старой эпохи (−0.019 LGB, −0.0116 TabPFN, −0.022 смоук)
   плюс этот — четыре точки, две эпохи бленда, один вывод.
2. **Разница real − placebo = +0.0008..+0.0011** — ровно масштаб известного
   ЛИНЕЙНОГО микро-сигнала, который ridge видит целиком (+0.0010). Деревья его
   не извлекают: он тонет в −0.012 штрафа за запоминание. Нового сигнала сверх
   линейного в остатке НЕТ.
3. **Линейный микро-сигнал жив, но уже оплачен лидербордом.** Против пака 1.666302
   ridge давал +0.000986, против текущего 1.665647 — +0.000851 (пересборка съела
   ~14%). Положительный ridge-пол
   НЕ прохудившаяся оболочка, а уже собранный урожай.
4. **safe117 ≈ full196** (−0.0112 против −0.0114): maxback-задетые колонки
   дополнительного сигнала в остатке не несут; production-safe усечение ничего
   не меняет и для стека.
5. Зеркало H1 с blend-фичей = без неё: калибровка пака уже сняла E[r | blend],
   стек поверх калиброванного бленда не имеет и этой оси.

Оговорка семантики: эталон 1.665647 — in-sample рефит на этом окне (честный OOF
того же бленда 1.665764), т.е. остаток чуть «переочищен» и замер слегка
консервативен — но старые доказательства мерились в той же семантике, а зазор
(0.0001) на два порядка меньше замеренных −0.011.

**Следствие для поиска то же, что и раньше, теперь и для новой эпохи:** любая
модель-функция этих признаков лежит в оболочке по построению; живое — другой ВХОД
(события/секвенсы, застоялость) и со-обучение, не стек.
