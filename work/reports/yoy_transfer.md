# Персональный сезонный перенос (YoY): ОПРОВЕРГНУТО

Дата: 2026-08-19. Скрипты: `work/scripts/yoy_{windows,check,check2,check3,build}.py`.
JSON: `work/reports/yoy_{check,check3,holiday_trait,build}.json`.

## Гипотеза

    A = gmv 2025-01-15..02-13   (прошлогодний аналог val-окна)
    B = gmv 2025-02-14..03-15   (прошлогодний аналог ТЕСТА, включает 8 марта)
    C = gmv 2026-01-15..02-13   (val-окно, наблюдаемо)
    D = gmv 2026-02-14..03-15   (тест, предсказываем)

    lp(D) − lp(C)  ≈  lp(B) − lp(A)          (lp = log1p)

«Личная сезонность устойчива между годами». Раньше применялись глобальный (+0.116)
и сегментные сдвиги, но никогда — персональная дельта из собственного прошлогоднего
поведения.

## Как проверено честно (главный методический шаг)

Прямая проверка corr(B−A, D−C) невозможна: D не наблюдаемо. Ключевое наблюдение:
данные покрывают 2025-01-01..2026-02-13, то есть **в двух годах наблюдается
календарный отрезок 01-01..02-13 (44 дня)**. Его хватает на точный структурный
аналог гипотезы — пара окон по 22 дня, замеренная в обоих годах:

    Xp = 2025-01-01..01-22   Yp = 2025-01-23..02-13     ← аналог пары (A, B)
    X  = 2026-01-01..01-22   Y  = 2026-01-23..02-13     ← аналог пары (C, D)

    d25 = lp(Yp) − lp(Xp)      «B − A»
    d26 = lp(Y)  − lp(X)       «D − C», и оно НАБЛЮДАЕМО

`corr(d25, d26)` — это ровно воспроизводимость персональной сезонной дельты через
год для одного и того же календарного перехода. Контроль — вторая пара по 15 дней
(15-29.01 / 30.01-13.02).

Три независимых теста + два контроля:

1. **Зеркальная пара** — воспроизводимость и оптимальный наклон переноса.
2. **Инкрементальный тест** — добавляет ли недостающая половина дельты что-нибудь
   поверх богатой базы. Важно: чемпион уже имеет `gmv_sum_ya_tgt` (для теста это
   ровно B), новой является только A. Поэтому база включает lp(Yp), а тестируется
   добавление lp(Xp).
3. **Праздничная черта** (`yoy_check2.py`) — закрывает возражение «зеркальная пара
   пересекает переход со слабой сезонностью, а реальная — 23.02 и разгон к 8 марта».
   Если «праздничная отзывчивость» есть как персональная черта, лифты на разных
   праздниках 2025 должны коррелировать между собой.
4. Контроль артефакта: автокорреляция дельт соседних 30-дневных окон при лаге 1
   (окна пересекаются) должна быть ≈ −0.5 при чистом шуме.
5. Контроль метода: та же кросс-праздничная корреляция, но для УРОВНЯ вместо лифта.

## Результаты

### 1. Воспроизводимость дельты через год ≈ 0

| выборка | corr(d25, d26) | наклон переноса s* |
|---|---|---|
| пара 22д, все 250k | **+0.0114** | +0.0125 |
| пара 22д, активные в 2025 (n=106 726) | +0.0161 | |
| пара 22д, активные в обоих (n=86 669) | +0.0184 | |
| пара 15д, все | +0.0072 | +0.0081 |

Гипотеза требует наклона 1.0 — замерено 0.0125, т.е. **усадка 99%**. Иначе говоря,
98.9% дисперсии персональной сезонной дельты — одноразовый шум, а не черта.

Жёсткая форма `lp(X) + s·d25_centered` монотонно ухудшается с ростом s
(RMSLE 2.1496 при s=0 → 2.1562 при 0.1 → 2.2211 при 0.3 → 2.8840 при 1.0).

Автокорреляция персональных дельт 30-дневных окон, **непересекающиеся пары**:
лаг 2 −0.021, лаги 3-11 в диапазоне −0.008…0.000. Контроль лага 1 (пересекающиеся):
−0.455 при теоретических −0.5 для чистого шума. Персональная дельта — почти
буквально белый шум.

### 2. Знак коэффициента ПРОТИВОПОЛОЖЕН гипотезе

Стандартизованная регрессия lp(Y) на богатую базу + оба прошлогодних окна
(n=250k, OLS, t-статистики по QR):

| признак | коэф | t |
|---|---|---|
| lp_Yp (прошлогодний аналог таргета) | **+0.0654** | +14.8 |
| lp_Xp (прошлогодний аналог базы)    | **+0.0721** | +16.9 |
| d25 = lp_Yp − lp_Xp при фиксированной базе | **−0.0700** | **−16.9** |

Гипотеза требует lp_Xp < 0 (дельта входит с плюсом). Замерено: **оба прошлогодних
окна входят с ПЛЮСОМ**. Прошлогодняя история работает как дополнительное
свидетельство об УРОВНЕ пользователя, а не как сезонная дельта. Оптимальный
коэффициент при дельте отрицательный и высоко значимый — это mean reversion,
прямо противоположное «переносу сезонности».

OOF RMSLE на зеркальной задаче: rich 1.668619 → +lp(Yp) 1.667299 → +lp(Xp) 1.666347.
Весь прирост (0.00095) достаётся уровневой интерпретации, при неверном для гипотезы знаке.

### 3. Гетерогенности нет

По децилям gmv_365: r от −0.036 до +0.032, без монотонности; у активных (A>0)
верхних децилей +0.015…+0.017. По силе прошлогодней сезонной реакции |d25|:
слабая +0.014, средняя +0.009, сильная +0.003, экстремальная +0.019. Ни один
подсегмент не показывает переноса.

### 4. Персональной праздничной черты не существует

Корреляции персональных лифтов между разными праздниками 2025 (лифт = log1p(факт
в ране) − log1p(ожидание из собственной 28-дневной базы), только юзеры с ненулевой
базой в обоих):

- среднее по 21 паре: **+0.0239**, максимум +0.0478;
- среднее в парах с раном 01-06.03 («8 марта», то самое, что переносим): **+0.0274**;
- контроль на УРОВНЕ вместо лифта: **+0.3645** — метод измерения рабочий.

То есть человек, сильно откликнувшийся на один праздник, не отличается по отклику
на другой. Возражение «зеркало не покрывает сильную сезонность» закрыто: сильная
сезонность есть, персональной черты в ней нет. Это независимо согласуется с
опровержением гипотезы «ДАРИТЕЛИ» (тир v8) и с потолком подгруппы.

## Побочные находки (важные для планирования)

1. **`gmv_sum_ya_tgt` полностью null на 29 из 31 обучающих срезов.** Окно
   [anchor−364, anchor−335] попадает в данные только при anchor ≥ 2025-12-31;
   ненулевые значения есть лишь на срезах 2025-12-31 и 2026-01-07 (плюс val и test),
   на остальных — null у всех 250 000 юзеров. То есть прошлогоднее окно чемпион
   фактически НЕ использует: коэффициент выучить не на чем, а «null / не-null»
   конфаундится с номером среза. Стоит либо убрать признак, либо оговорить явно
   (сейчас ни то ни другое). То же касается `gmv_sum_ya_wide`, `ord_days_ya_*`.
2. **Уровневое (не дельтовое) прочтение прошлогоднего окна тоже мертво на нашей базе.**
   Направления lp(A), lp(B), lp(A)+lp(B), резидуализованные против базиса
   (novelty 0.39 / 0.30 / 0.24), дают cov с ошибкой теста +0.0014 / +0.0031 / +0.0028
   и максимальный выигрыш **6e-07 / 2.9e-06 / 2.4e-06 RMSLE**. Знак правильный
   (согласуется с положительными коэффициентами зеркала), величина ничтожна.
3. **Признак (B−A) физически невозможно обучить в текущем протоколе**: ни на одном
   обучающем срезе оба прошлогодних окна не существуют (нужны данные до 2025-01-01).
   Он был бы признаком «только для теста». Пункт 5 задания (тир v9) поэтому не
   запускался — и по отсутствию сигнала, и по невозможности обучения.

## Методическое ограничение (записать в протокол)

`predict_lb.py` оценивает ортогональную часть направления через ковариацию с
**валидационным** таргетом (×1.052). Поэтому эффект, специфичный именно для
тестового окна (а гипотеза YoY-переноса — ровно такой), для него **невидим**:
LB-пробы сами по себе гипотезу не опровергают, они лишь показывают, что в
измеримой части сигнала нет. Опровержение даёт зеркальный тест (§1-2), который
измеряет механизм напрямую на наблюдаемых данных. Обе линии сходятся.

## Вердикт

**ОПРОВЕРГНУТО, направление закрыто.** Не тремя способами «слабо», а тремя способами
«отрицательно»:

- воспроизводимость персональной сезонной дельты через год: 0.011 (нужна ~1.0);
- оптимальный коэффициент при дельте на богатой базе: −0.070 (t = −16.9), знак
  обратный гипотезе — это mean reversion, а не сезонность;
- персональной праздничной черты не существует (кросс-праздничная корреляция
  лифтов +0.024 при контроле уровня +0.36);
- на реальном тестовом окне оптимальный вес поправки −0.0002, потолок выигрыша
  4e-08 RMSLE; проба «база + 0.45·h» хуже базы на 0.0051.

Механизм тот же, что у уже закрытых направлений (дарители v8, zero-push, левый хвост
калибровки): персональное поведение в 30-дневном окне — почти чистый пуассоновский
шум поверх уровня, и всё, что воспроизводится между окнами, это уровень, который
чемпион уже знает лучше.
