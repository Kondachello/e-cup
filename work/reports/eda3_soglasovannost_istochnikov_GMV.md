## 2. КАНДИДАТ: seg_gc_nocat — кросс-дневная атрибуция catalog-заказов

**Определение**: день с gmv_cat>0 при cat=0 (конверсия признана в день без сессии каталога). Таких строк 68 564 = **20.7%** всех cat-gmv дней; доля стабильна во времени (18.6–24.3% по месяцам, слома нет). Сегмент = юзеры с ≥1 таким днём в истории: **30 939 на вал-якоре (12.4%), 32 602 на тест-якоре (13.0%), Jaccard 0.949**.

**Почему НЕ закрытый класс**: событие — СОВМЕСТНОЕ дневное (joint), из оконных сумм оболочки (cat_days_w, c2o_days_w, gmv_cat_w) не восстанавливается; эмпирически прокси-набор оболочки [log n_gc_days, log n_gs_days, log n_gmv_days, cat_rub_share, log sum_gmv, log sum_gc, has_gc] объясняет лишь R²=0.21 вектора, и corr с остатком выживает: 0.0138 → 0.0116. Добавка recency (rec_cat, rec_gc, rec_ord — в оболочке) и края прогноза (b, b²) в партиализацию: corr 0.0119, OOF gain партиализованного вектора **1.11e-4** — не тень оболочки, не recency, не край прогноза.

**Механизм**: заказ из catalog-атрибуции без сессии в день заказа = намерение сформировано раньше (кросс-дневная/кросс-девайсная атрибуция) — «возвратный покупатель» с меньшей видимой активностью на рубль GMV. Все модели активность-центричны и систематически НЕДОпредсказывают таких юзеров.

**Численный сигнал** (вал, e = log1p(target) − blend):
- corr(x, e) = 0.0138 (7 сигм при поле 0.002); внутри 95 162 cat-покупателей corr = 0.0188.
- mean_e сегмента +0.0596±0.0099 vs вне сегмента (среди cat-покупателей) −0.0169±0.0068 → разрыв **+0.077 (~7σ)**.
- Матчинг по децилям бленда: разрыв **+0.0742 ± 0.0111** (10/10 децилей) — не «края прогноза».
- Бинарный корректор, честный 2-fold OOF: **gain 1.77e-4** RMSE (δ по фолдам +0.068 / +0.083; беты по 4 фолдам 0.103/0.117/0.070/0.069 — все положительные).

**Концентрация (киты)**: выброс топ-0.1% юзеров по |d|: gain 1.55e-4 → **1.46e-4 (94% выживает)**; улучшены **58.9%** юзеров — массовый сегментный сдвиг, не китовый трейд (грубая метрика top1%=8.6x отражает симметричные тяжёлые хвосты d, а не источник гейна).

**Воспроизводимость вне бленда** (разрыв сегмента, cat-покупатели): blend +0.0765, kostya46_cal +0.0647, fusion_v3_avg_cal +0.0652, wklin +0.0936, gseq_big_s42_cal +0.0593 (все ±0.0120) — слепое пятно всего семейства, включая секвенс-модели.

**Стабильность во времени**: эффект жив и для свежих невязок (последняя ≤90д: mean_e +0.0540±0.0162), и для старых (>90д: +0.0629±0.0125).
