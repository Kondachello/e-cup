## 1. Проверка закона

меряю разброс k. Шесть осей, охватывающих σ от 0.11 до 2.6:

| ось | σ_κ эмпирически | σ_κ по закону | отношение |
|---|---|---|---|
| уровень | 1.302 | 1.408 | 1.08 |
| сегментная ступенька | 0.411 | 0.499 | 1.22 |
| стек по признакам | 0.114 | 0.111 | 0.97 |

| дельта fusion | 0.723 | 0.745 | 1.03 |
| крошка (шум) | 2.420 | 2.635 | 1.09 |

Среднее отношение **1.08**, разброс 0.97–1.22. Закон работает на всём диапазоне.

Вывод в двух строках: `κ = c_test/c_val`, `σ(c) = sd(e·h)/(√n·mean(h²))`,
`G_mse = c_val²·mean(h²)`, откуда `σ_κ = σ(c)/|c_val| = sd(e)/√(n·G_mse)`
при `sd(e·h) ≈ sd(e)·√mean(h²)`.

## 3. Разведение трёх величин

| величина | что это | значение |
|---|---|---|
| σ_ариф | ошибка восстановления k из арифметики скоров | ≈0 (скоры точные) |
| **σ_i** | расхождение k на 50k публики и истинной k окна | **закон, 0.04–2.9** |
| τ_внутри класса | истинный разброс κ между осями одного класса | 0.056 (REML), но см. ниже |
| τ_между классами | разброс средних по классам | ≈0.40 |

**Главное из разложения: почти весь наблюдаемый разброс κ — МЕЖДУ классами,
а не внутри.** Это механистически оправдывает твой синтез.

Оговорка, которую обязан сделать: τ_внутри **неоднороден по классам**. Класс
«бленд» кучный (0.601 / 0.529 / 0.550), класс «стек» разъезжается (0.307 / 0.000
при σ_i=0.132 — это 1.65σ). Единый τ не описывает оба, а 12 точек в 7 классах
не позволяют оценить классовые τ_c по отдельности.

## 4. Формула дозы

```
w_i = V_приор / (V_приор + σ_i²),      σ_i = sd(e)/√(n · 2·sd(e) · G_i)
κ̂_итог = w_i · κ_замер + (1 − w_i) · μ_класса
```

С `V_приор = 0.042` (разброс между классами, как в твоём синтезе):

| ось | G | σ_i | **доза w** |
|---|---|---|---|
| уровень (сдвиг +0.1163) | 0.0116 | 0.038 | **0.97** — верить замеру |
| стек по признакам | 0.00096 | 0.132 | 0.71 |
| дельта бленда | 0.00037 | 0.212 | 0.48 |
| ось e_new / проба | 0.00020 | 0.289 | 0.33 |
| сегментная ступенька | 0.000067 | 0.499 | 0.14 |
| крошки | 0.000002 | 2.887 | **0.005** — замер игнорировать |

**Точка перелома `w = 0.5` при `σ_i = 0.205`, что отвечает выигрышу оси
`G = 0.0004 RMSLE`.**

> **Правило одной строкой: ось с валидационным выигрышем выше 0.0004 —
> верить её собственному замеру; ниже — верить классу.**

Это заменяет мой плоский `w = 0.28` (он был верхней оценкой для мелких проб)
и уточняет твой синтез: не «сколько замеров в классе», а «насколько крупна
сама ось».

## 5. LOO: моя иерархическая модель ПРОИГРАЛА

Честный результат, засчитываю в твою пользу.

| модель | LOO-логскор |
|---|---|
| **B) твой синтез «≥2 замера — верь классу»** | **−0.1911** |
| A) моя прежняя плоская w=0.28 | −0.2521 |
| C) моя иерархическая с σ_i из закона | −0.2798 |

Проверено на устойчивость: множитель угаданных `G` от 0.2 до 5.0 — ранжирование
не меняется ни разу. То есть иерархическая проигрывает **не из-за моих догадок про G**.

**Почему проигрывает.** REML даёт `τ = 0.056`, модель становится переуверенной
в классах, где разброс на самом деле больше (стек: z = +1.93 и −2.05).
Средний |z| = 0.73 при ожидаемых 0.8 — в среднем калибровка нормальная, но
хвосты рвутся. Двенадцати точек в семи классах для классовых τ_c не хватает:
модель неидентифицируема.

**Вердикт: рабочим правилом остаётся твой синтез, но с моей σ_i вместо плоской
дозы.** То есть: приорное среднее — по классу (твоё), вес свежего замера —
по закону (моё). Именно эта комбинация и есть строка B в таблице: она уже
использует σ_i в правдоподобии.

## 6. Что закрыло бы вопрос

Единственное, чего не хватает — **настоящие G для всех 12 осей**. Шесть из
