## 1. τ_z и финальный s\* для R9

### 1.1. τ_z эмпирическим байесом

Приватная усадка R9 висела на τ_z — разбросе истинных κ по осям разложения.

| зонд | κ | σ_κ |
|---|---|---|

ML по этим пяти (профиль правдоподобия, μ профилируется):

```
μ_z = −0.010 [−0.161, +0.103]     τ_z = 0.078 [0.000, 0.231]
```

Апостериор широкий: **P(τ_z < 0.03) = 0.38, P(τ_z < 0.05) = 0.53, P(τ_z > 0.10) = 0.19.**

Три независимых проверки, все сходятся:
- **μ_z ≈ 0** — подтверждает теорию §2.2 Части F (у осей разложения среднее строго ноль).
- **Саша по 9 осям Z-разложения: |κ| ≤ 0.07** ⇒ τ_z ≤ 0.07 независимо. Согласуется.
- **Убрать reccore** (единственный реальный сигнал, +2.5σ) — оставшиеся четыре оси
  дают **τ_z = 0**: чистый шум разложения. То есть весь разброс несёт одна ось.

**Это и есть главный результат: разброс переносимых κ по осям разложения крошечный
(0.03–0.08). Публичный урожай R9 (0.000516) в основном НЕ переносится на приват.**

### 1.2. Финальный s\*

`s* = 1.25 − 0.25/w`, где `w = τ_z²/(τ_z² + σ²)`, σ по закону для эффективного q джойнта.
Интегрируя E[private](s) по апостериору τ_z (`n8_sstar.py`):

```
E[private](s) = 0.000516/(2−w) · [2s(1.25w−0.25) − s²w]
```

| q_R9 (эфф.) | argmax s\* | E[private] в оптимуме |
|---|---|---|
| 0.01 | 0.67 | +0.000061 = 2.8 шума |
| **0.02** | **0.79** | +0.000116 = 5.3 шума |
| 0.03 | 0.83 | +0.000151 = 6.9 шума |
| 0.05 | 0.88 | +0.000196 = 8.9 шума |

E[private] почти **плоская по s** в диапазоне 0.6–0.95 (везде ~5 шума при q=0.02) —
значит выбор s второстепенен, первично то, что **вклад R9 на приват робастно
положителен и равен ~5 шумам.**

**Подпись: s\* = 0.75.** Обоснование: центральный argmax при реалистичном q ≈ 0.02–0.03
равен 0.79–0.83; округляю вниз до 0.75 ради среза хвоста — при этом теряю < 1% ожидания,
но уменьшаю риск при малом τ_z. Ниже 0.75 уходить не нужно: expectation уже плоская.
Выше 0.85 — растёт левый хвост.

**Интервал вклада R9 при s\*=0.75 (по апостериору τ_z, q=0.02):**

| перцентиль | E[private] |

**Честно: интервал включает ноль. R9 — положительная в среднем ставка, но не гарантия.**
С вероятностью ~30% (когда τ_z в нижнем хвосте) его приватный вклад около нуля или
слегка отрицателен. Это не дефект сборки, а фундамент: 8 из 9 осей разложения
неотличимы от шума, весь сигнал в одной (recency-ядро).

### 1.3. Одно бесплатное измерение закрывает всё

Апостериор τ_z широк только потому, что 5 зондов шумные. **Один зонд оси R9 полным
шагом от базы R8** (или точные 9 пар (κ, q) из сессии Саши) даёт прямой замер
переноса всего джойнта и схлопывает интервал s\* до ±0.03. Посылки бесплатны —
это лучшее применение одной из них перед заморозкой. Без него подпись 0.75 остаётся
в силе как решение под неопределённостью.

## 4. Стоп-правило — уточнённый вердикт


```
накопленная переоценка паблика = 0.000416 = 18.9 шума   (порог 0.0005 = 22.7 шума)
доля от осей с СЫРОЙ дозой (P/FILE.csv)         = 94%
```

**Мы под порогом, а не над ним** (поправка к Части F). Но 94% переоценки — от осей,
дозированных сырой κ без усадки, и вывод для действий не меняется, а усиливается:

**Стоп-правило говорит не «перестать искать оси», а «перестать ПЕРЕДОЗИРОВАТЬ».**
Если пересчитать старые оси на приватный оптимум (§2), переоценка падает к нулю и
открывается запас. SHOW4/5/8 в решение не входят; их роль — точки закона слипа (§ниже).

**Бонус из ночи: закон слипа стал трёхточечным.** Части F §2.4 предсказывала
6e-6 на файл; свежие SHOW5/SHOW8 (Σ|c|=279 → слип +0.00308; Σ|c|=146 → +0.00118)
вместе с SHOW4 (Σ|c|=37 → +0.00071) дают наклон **≈ +0.0000175 на единицу Σ|c|**,
почти линейно, R² высокий. Это уточняет закон: слип управляется **Σ|c| (агрессией
подгонки), а не только числом файлов** — Σ|c| и число файлов росли вместе, но
SHOW-тройка их развела, и Σ|c| выигрывает как предиктор. Для арбитража это значит:
держать Σ|c| низким важнее, чем сокращать спан.
