# Идеи фичей v3 (для раунда 4)

Приоритизировано по ожидаемому эффекту с учётом уроков раундов 1–3
(январская ловушка = ковариатный сдвиг уровня; тест = мартовское окно с 8 марта).

## A. Ранговые/нормированные фичи — приоритет 1 (устойчивость к сдвигу уровня)
Деревья, обученные на абсолютных суммах, ломаются при сдвиге уровня между окнами
(январь: 1.63 vs декабрь: 1.52 у прямых моделей). Кросс-юзерные percentile-ранги
внутри якоря инвариантны к глобальному сдвигу:
- pct_rank(log_gmv_sum_{30,90,365}), pct_rank(ord_days_{90,365}),
  pct_rank(dec_gmv_h30), pct_rank(rec_order), pct_rank(searches_30),
  pct_rank(gmv_per_ordday_365)
- отношения к медиане якоря: gmv_30 / median_positive(gmv_30 по якорю)

## B. Сезонные (мартовское окно) — приоритет 1
- Разбить «окно год назад» [A-364, A-335] на трети: ранняя/средняя/поздняя
  (для теста поздняя треть = 4–13 марта 2025 — предмартовский пик).
  gmv + ord_days по третям → «подарочный» профиль пользователя.
- gift_spike_flag: gmv поздней трети > 2× медианной недели пользователя.

## C. Динамика/регулярность — приоритет 2
- burstiness: ord_gap_std / ord_gap_mean (кучность заказов);
- weekly concentration: max дневной gmv / gmv_90 (есть gmv_concentration в v2 для 365d — добавить 90d);
- тренд ord_days: ord_days_30 vs ord_days_b30_59 (лог-разность).

## D. Поведенческие профили — приоритет 2
- weekend_share: доля order-дней в сб/вс (365d) — гифтеры vs рутинные покупатели;
- both_surface_share: доля активных дней с search И cat одновременно (90/365d);
- search_share_trend: gmv_search_share_30 − gmv_search_share_365.

## E. Эмбеддинги из GRU — приоритет 3
- last hidden state (96-dim) обученного GRU → PCA top-16 → фичи для GBDT.
  Дёшево получить, добавляет секвенс-информацию деревьям.

## F. Обучение (не фичи)
- Мульти-горизонтные вспомогательные таргеты (7d/14d) для NN;
- Модель на нормированном таргете y/(1+gmv_365/12) как компонент бленда;
- Каскад из per-anchor rank-таргета (предсказывать ранг юзера в окне) + маппинг в уровень.

## Реализовано в build_features_v3.py (запущено)
A: 9 ранговых фичей; B: трети ya-окна (6) + gift_spike; C: burstiness, conc_90,
ord_days trend; D: weekend_share (2), both_surface (2), search_share_trend.
Подключение: env USE_V3=1 (джойн .v3.parquet в load_anchor).
