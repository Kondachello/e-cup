# EDA3, линза «карта остатка 2D»: где живёт ошибка бленда — итог: пусто, закрыто с числами

Дата: 2026-08-22. Эталон: `blend` из `work/preds_pack/val_preds.parquet`,
воспроизведён точно **1.6656470**; остаток e = log1p(target) − blend, mean(e) = −0.0066
(известный уровень, пробит LB-зондами). Оси построены только из истории до якоря
2026-01-14 (streaming-агрегация train.parquet). Скрипты:
`eda3_resid_map2d_{agg,maps,inter,margins,searchint,final,chancells}.py`,
числа: `eda3_resid_map2d.json`.

**Вердикт: кандидатов нет.** Вся структура остатка, видимая 2D-картами, либо
(а) статистически неотличима от шума после снятия 1D-маргиналов, либо
(б) лежит строго внутри закрытого класса линейных корректоров (доказано span-тестом),
либо (в) имеет честный потолок ниже 5e-5. Пустой список — честный результат линзы.

## Протокол

12 карт 2D (квантильные бины 5–14 на ось, ячейки n>30, всего ~540 ячеек):
активность x чек (act90 x aov365), свежесть x частота (rec_ord x freq365),
явка x уровень (act28 x lvl), rec_any x lvl, канал x уровень (chan = доля gmv_search),
корзина x частота, день-недели-концентрация x частота, темп активности (d_mean90,
d_std90) x активность, доля поисковых дней (search_int = search_days_90/active_days_90)
x уровень, blend x rec_ord, blend x chan. Для каждой: сырые mean(e)/SE/z по ячейкам;
затем взвешенная двухфакторная ANOVA (mu + строка + столбец) и z взаимодействия —
чтобы отделить «2D-карман» от произведения маргиналов. Все gain'ы — кросс-фит
5 фолдов по юзерам; для каждого сигнала — концентрация (top-0.1%/top-1% вклада)
и сплит-халф.

Факт о юниверсе: у всех 250k юзеров rec_any ≤ 29 дней и act90 ≥ 2 — юниверс уже
отфильтрован по свежей активности, «спящих» ячеек не существует в принципе.

## 1. 2D-карманов нет: взаимодействие = шум на всех картах

Сырые карты показывают избыток ячеек |z|>2 (напр. act90 x aov365: 9 при ожидании 3.3;
blend x rec_ord: 10 при 2.0; max|z| = 8.18 на search_int x lvl) — но это целиком
1D-маргиналы плюс глобальный сдвиг −0.0066. После снятия маргиналов (ANOVA):

- по 11 картам / 542 ячейкам: |z_int|>2 — **23 при ожидании 24.7**; |z_int|>3 — **2 при
  ожидании 1.5**; max|z_int| = 3.07 (порог Бонферрони 5% для 542 ячеек ≈ 3.7 — не пройден).
- честный OOF interaction-only корректора лучшей карты (chan x lvl, shrink 200):
  **−0.000034** (минус!). Последовательный стек пяти карт полными ячейками (shrink 100):
  **−0.001054** — компаундное переобучение.
- in-sample потолок interaction-only ≤ 0.000256 на карту (act90 x aov365) — даже
  нечестный максимум ниже порога задачи.

Ячейка z=8.18 (search_int≥0.98 x lvl<4.1, n=13.9k, mean_e=−0.074) имеет z_int=−0.35 —
чистое произведение маргиналов, не карман.

## 2. Единственный живой маргинал — search_int; вскрытие показало закрытый класс

**search_int = search_days_90 / active_days_90.** Верхний бин (≥0.947, по факту почти
все ровно 1.0 — «только ищет, ничего не кладёт и не заказывает 90 дней») — **n=50 712
(20% юзеров), mean_e = −0.0464, z = −6.7**: бленд систематически ЗАВЫШАЕТ этих юзеров.
Бин 1 (0.5–0.645) недооценён (+0.0355, z=+3.5). Margin-корректор (10 бинов, кросс-фит):

- честный OOF **+0.000159**; по 5 сидам фолдов K=5: +0.000151±0.000011 (min +0.000131);
  сплит-халф 10 сплитов: +0.000163±0.000034 (min +0.000086). Сигнал реален.
- концентрация **отрицательная**: top-0.1% = −0.33, top-1% = −0.91 — выигрыш несёт
  масса (78.7% в верхнем бине на 51k юзеров), киты против. Профиль переносимый —
  редкость для корректоров.
- НЕ выражается закрытыми осями сегментов: после калибровки бленда вентилями gain
  +0.000160 (не падает), после бленд x сегменты (давность x заказные-дни-90, ось (г)
  из blend_segments) — +0.000156. Сама калибровка бленда по вентилям даёт **−0.000055**
  (бленд откалиброван), бленд x сегменты — **−0.000300**.

**Но span-тест закрывает:** cv-ridge на рангах 8 колонок закрытого cnt-корректора
снижает маргинал до +0.000051, а добавление квадратичных произведений рангов всего
4 колонок (**search_days_90, active_days_90, searches_90, ord_days_90** — все есть в
78 колонках cnt/cnt_rank) забирает его в ноль: **−0.000004**. Сам quad-span даёт
+0.000231. То есть search_int — репараметризация сигнала, уже живущего в закрытом
классе «линейные корректоры остатка» (LB-перенос 0–0.31), и строго доминируется
cnt_rank (+0.000584 OOF, уже рекомендован на LB-калибровку ночным отчётом
night_corrector_variants). Новой информации нет.

Побочное для интерпретации cnt_rank: маргинальная часть его сигнала (доля-поиска)
несёт ~+0.00016 с ОТРИЦАТЕЛЬНОЙ концентрацией — если что-то из корректора и
переносится на LB, то скорее эта массовая компонента, а не китовая.

## 3. Остальные вскрытые аномалии — реальные, но микроскопические и внутри агрегатов

- **«Ушедшие тяжёлые»** (rec_ord>90, но ord_days365≥23): n=233, mean_e=−0.346±0.120 —
  бленд сильно завышает бывших частых покупателей, замолчавших 90+ дней. Сплит-халф
  честно: **+0.000028±0.000006**. Реально, но в 1.3 шума ЛБ, и ось = функция колонок
  ord_days_b90_179/ya_wide закрытого корректора.
- **chan x lvl, два зеркальных кармана** в нижнем уровне (gmv365<60р): chan∈[0,0.83]
  n=2659 mean_e=+0.091 (недооценка) против chan∈(0.83,0.94] n=337 mean_e=−0.219
  (переоценка). Знак устойчив в 20/20 сплит-халфов — описательно это самая настоящая
  локальная кривизна бленда. Но in-sample потолок обеих ячеек 4.6e-5, честный
  interaction-корректор карты −0.000034, ось chan — функция gmv_search_365/gmv_cat_365
  (денежные колонки 117-колоночного корректора). Закрыто по величине и по классу.
- Все прочие маргиналы: rec_any +0.000097 → +0.000045 после закрытых осей; d_mean90,
  chan, rec_ord, act28 ≤ +0.000033 и умирают после кондиционирования; blendv, freq365,
  aov365, d_std90, dow_top — нули или минусы.

## 4. Согласование с night_blend_stability

Согласуется полностью: там переход блендов дал выигрыш во всех терцилях прогноза без
единого проигрышного сегмента, диффузный по массе (top-1% несёт 10%); здесь — после
снятия маргиналов не существует ячейки, где бленд смещён сверх шума и порога
Бонферрони. Оба замера говорят одно: у бленда не осталось «карманов смещения»,
выражаемых историей юзера, кроме уже учтённого класса корректоров.

## Что это значит для очереди

Линза закрыта: сегментно-ячеечная плоскость (любые 2D-комбинации активность/чек/
свежесть/частота/явка/уровень/канал/корзина/темп/доля-поиска/значение прогноза)
исчерпана — честные потолки 3e-5..1.6e-4, всё внутри закрытого класса. Ресурс
двигать только живыми направлениями (событийные трансформеры, joint fusion, S-оси
тестового окна). Если cnt_rank пойдёт на LB-калибровку — его массовая (не китовая)
компонента ≈ search-доля; ждать переноса имеет смысл именно от неё.
