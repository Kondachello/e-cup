# План: часть A (механизм переноса) и часть B (бюджет финала)

Женя, старт 20.08.2026. Дедлайны: A — 48 ч, B — 72 ч.

## Часть A — механизм κ (доля вал-оптимума, дожившая до теста)

**Требование:** формула `κ_pred(свойства оси)` с выводом, валидированная на всех
замеренных точках, MAE ≤ 0.10. Либо честное доказательство непредсказуемости.

**Замеренные точки (даны заказчиком):**

| ось | κ |
|---|---|
| дельта пересборки бленда №1 | 0.601 |
| дельта пересборки бленда №2 | 0.529 |
| стек по признакам, вариант 1 | 0.307 |
| стек по признакам, вариант 2 | 0.00 |
| своп ретрейнов | −0.20 |
| сегментная ступенька | 0.05 |
| уровень | 0.20 |
| ось e_new | 0.09 |
| де-шринк проб | 0.63 |
| крошки | 1.12 |

**Рабочая гипотеза (двухфакторная):**

```
κ = S(ось) * A(ось)
S — динамическое выживание: в какой компоненте разложения живёт выигрыш оси
    (mu переживает сдвиг окна полностью, s — с коэффициентом lam, e — никогда)
A — статистическая усадка: подгонка k параметров на n строк завышает вал-выигрыш
    на k*sigma^2/n, на тесте этого завышения нет
```

**Что посчитать своим аппаратом:**
1. затухание r(k) между окнами val (15.01–13.02) и test (14.02–15.03) — уже есть;
2. SE публики 50k — свой расчёт;
3. стену отбора (явка сегментов) — своя же находка про юниверс;
4. для каждой оси — число свободных параметров и на каком объёме подобрано.

**Первички:** `predict_lb.py` MEASURED, json r6/u/x/w1, KNOWLEDGE «законы переноса».

**Координация с Олей:** у неё эмпирика (регрессия κ по наблюдаемым признакам оси),
у меня механизм (вывод из разложения дисперсии). Пересечение — общий список
свойств оси; расхождение прогнозов двух подходов само по себе информативно.

## Часть B — бюджет финала

**Требование:** формализованная стратегия трат + считалка-скрипт «состояние →
следующее действие», план по дням на 9 дней с числами.

Решается как задача остановки: 5 попыток в день, до заморозки 31.08 12:00,
цена зонда 0.0002–0.0003, приор класса оси даёт ожидание, κ из части A даёт
переносимость, SE public 0.0056 / private 0.0028, перенос public→private 0.584.

**Порядок:** A даёт κ_pred → B использует его как вход. Поэтому сначала A.
