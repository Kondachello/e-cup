## 1. Формула восстановления коэффициента

Скор файла: `S² = mean((m − t)²)`. Шаг `Δ = b·g` от базы даёт

    S(b)² = F0² − 2·b·c + b²·q ,     c = mean(g·(t − m0)) ,   q = mean(g²)

Шаг у всех пяти подобран так, что **Q = b²·q одинаков и равен 2·F0·0.0002 = 0.00065919**
(с поправкой на клип: реальный `mean(Δ²)` равен ровно этому числу у всех пяти).
Тогда при нулевом коэффициенте каждый файл теряет ровно **0.00019999** ≈ 9.1 шума замера.

Обозначим **κ = b\*/b** — во сколько раз оптимальный шаг больше применённого:

    κ = (F0² − S² + Q) / (2Q)                                 ← точная
    κ ≈ (1 − ΔS/0.0002) / 2 ,   ΔS = S_замер − 1.6479653      ← линейная, ошибка < 1e-3

Читается так: **ΔS = +0.0002 → κ = 0** (коэффициент нулевой); **ΔS = 0 → κ = 0.5**;
**ΔS = −0.0002 → κ = 1** (оптимум ровно там, куда шагнули); **ΔS = −0.0006 → κ = 2**.

Дальше:

    c   = κ · b · q            (сам коэффициент, если нужен в абсолютных единицах)
    b*  = κ · b                (оптимальный шаг ОТ БАЗЫ)
    выигрыш в оптимуме = κ² · 0.0002        на каждое направление
    суммарный выигрыш  = (Σ κᵢ²) · 0.0002   потому что направления ортогональны

Чтобы получить итоговый файл: взять базу и прибавить `Σ κᵢ·bᵢ·gᵢ`, то есть по каждому
направлению взять файл Pᵢ, вычесть базу, умножить на κᵢ и сложить всё с базой.
Направления `gᵢ` лежат в `work/reports/probes5.json` только числами; сами векторы
пересобираются `probes5_make.py` за минуту, либо берутся как `log1p(Pᵢ) − log1p(база)`.

**Усадка на шум замера, обязательна.** Один подобранный по публичной части коэффициент
несёт фиктивный выигрыш 0.000022 (`noise_floor.py`), то есть κ измеряется с
**σ(κ) = √(0.000022/0.0002) = 0.332**. Оптимальная доля применения
`a = 1 − 0.11/κ̂²` (обрезать в [0,1]):

| κ̂ измеренное | 0.33 | 0.5 | 0.7 | 1.0 | 1.5 | 2.0 |
|---|---|---|---|---|---|---|
| применять долю a | 0.00 | 0.56 | 0.78 | 0.89 | 0.95 | 0.97 |
| честный ожидаемый выигрыш | 0 | 0.000028 | 0.000076 | 0.000178 | 0.000428 | 0.000778 |

## 5. ВАЖНО: знак шага у mdl_amber перевёрнут против задания, и вот почему

1. Теория «оптимум уехал вверх вместе с ростом ρ» верна, но шаг
   по ней уже сделан, причём не глядя.

   довод сам по себе не решает — но знак у него отрицательный.
3. **Предсказатель, симметричная проверка.** Шаг вверх даёт 1.648598, шаг вниз 1.648208,
   ровно антисимметрично относительно 1.648203 — как и обязано быть для точной алгебры

Итого шаг вверх ожидаемо стоил бы −0.00040, шаг вниз ожидаемо бесплатен и может дать
до +0.0002. Информация из замера одна и та же при любом знаке: κ восстанавливается по
той же формуле, только с `b = −0.01664`. -1.0}` на `+1.0` и

## 6. Устройство направлений

**mdl_amber.** `g = m0 − proj_{1, mdl_tektit, e}(m0)`, шаг −0.01664. Разброс файла 1.62301.

**mdl_gabbro.** Из `train.parquet`: GMV каждого пользователя за **2025-02-14..2025-03-15** (тот же
календарный отрезок, что тест: 14 февраля, 23 февраля, 8 марта) минус его обычный уровень:
`log1p(GMV в окне) − log1p(30·GMV за остальной 2025 / 335)`. Это ровно окно признака
`gmv_sum_ya_tgt` (`build_features.YEARAGO = (364, 335)` от якоря 2026-02-13), который
**тождественно пуст на всех обучающих якорях**: данные начинаются 2025-01-01, поэтому
«год назад» для июльских-декабрьских срезов лежит вне данных. Модели этой величины не
видели ни разу — то самое условие «невидима на обучающих якорях», без которого поправка,
по правилу кампании 20.08, стоит ноль.
*Пользователи без истории в окне:* 20.85% пользователей (первое событие позже 2025-02-13)
в феврале-марте 2025 ещё не наблюдались — им поставлен **ровно ноль после стандартизации**,
то есть шаг их не двигает; среднее и разброс считаются только по 79.15% наблюдавшихся.
У наблюдавшихся, но не купивших в окне (GMV = 0 — это ровно половина, 50.2% от 197871),
величина считается честно и выходит сильно отрицательной — это законный сигнал «в прошлые
праздники не тратил», а не пропуск. Сырое распределение до стандартизации: среднее −1.320,
sd 1.957, квантили 1/50/99% = −5.56 / −1.02 / +2.94.

потолок любой краевой поправки 0.000106. Если понадобится пятая попытка подо что-то
другое — жертвовать надо этой.
