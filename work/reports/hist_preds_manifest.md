# Манифест: предикты семейств на исторических якорях (для части C / зеркального κ)

Дата: 2026-08-22. Запрос Жени: предикты нескольких НЕПОХОЖИХ семейств моделей на
исторических якорях с ПОЛНЫМ таргетом — чтобы оценивать перенос качества между
окнами без траты LB-попыток.

Скрипт: `work/scripts/predict_at_anchor.py` (веса из `work/models`, функции
предсказания импортированы из `final_submission/inference.py` — тот же код, каким
собирается сабмит). Все прогоны лёгкие (1–3 с на пару), очередь не понадобилась.
Числа ниже — из `work/preds_hist/_results.json` (пишется скриптом).

## Файлы

Каталог `work/preds_hist/`, юниверс всюду один — 250 000 user_id из
sample_submit, отсортирован; join строго по `user_id`.

| файл | колонки | что это |

| `target_a{ISO}.parquet` | user_id:i64, target:f64 | ФАКТ GMV за (якорь, якорь+30] — окно полное, нулей-пропусков нет |
| `_results.json` | — | журнал: mean_log1p, RMSLE, санити-числа |

Пятое семейство лежит не здесь, а в признаках:
`work/features/anchor={ISO}.seqoof.parquet` (user_id, seqoof_pred:f32) — но
seqoof_pred это **E[log1p(y30)]**, для сопоставления с pred брать
`expm1(seqoof_pred)` (или наоборот, всё сравнивать в log1p — метрика всё равно
живёт там).

## *ГЛАВНАЯ ОГОВОРКА: in-sample у четырёх семейств, честный только seqoof

Сохранённые веса всех четырёх моделей — это **финальный ретрейн**
(train + gap + val): трейнеры сохраняют модель ПОСЛЕ дообучения на валидации.
Все три исторических якоря входят в их обучающие наборы (страйд-14 сетка от
2026-01-14 проходит ровно через 12-31, 12-17, 12-03, 11-19; у behavonly_s1337
вообще все 27 якорей). Поэтому RMSLE выше — **слегка оптимистичен**.

Размер оптимизма ИЗМЕРЕН на val-якоре (2026-01-14 тоже in-sample для ретрейна,
а честный val-скор этих же конфигураций известен из мет):

| модель | RMSLE из весов на val (in-sample) | честный val (val-фаза, из меты) | оптимизм |
|---|---|---|---|
| twl_v7_s1337 | 1.6460 | 1.6938 | −0.048 |
| mlpziln_c42 | 1.6658 | 1.6848 | −0.019 |
| behavonly_s1337 | 1.6683 | 1.7111 | −0.043 |
| weak_ft_recency | 1.6864 | 1.7291 | −0.043 |

То есть абсолютные скоры на исторических якорях занижены на ~0.02–0.05.
seqoof же обучен ТОЛЬКО на якорях ≤ 2025-11-12 (time-split OOF,
`work/scripts/seq_oof_features.py`) — на всех трёх якорях он честный.

Что из этого следует для κ:
- **сравнения МЕЖДУ четырьмя семействами внутри якоря** — ок: у всех одинаковый
  протокол (ретрейн через val, якорь in-sample), сдвиги одного порядка;
- **сравнение любого из четырёх с seqoof по абсолютному RMSLE** — нечестно в их
  пользу на ~0.02–0.05; сравнивать ранги/корреляции прогнозов, а не скоры;
- **перенос между окнами** (ради чего всё): смотреть ИЗМЕНЕНИЕ метрик между
  якорями у фиксированной модели и согласованность этих изменений между
  семействами — аддитивный in-sample сдвиг при этом в основном сокращается;
- окна разной трудности сами по себе: 11-19 и 12-03 — предновогодний разгон
  (mean_log1p таргета 2.44/2.51), 12-17 — пик+спад (2.39), val 2.24. Уровневые
  сдвиги прогнозов между якорями — это сезон, а не деградация модели.

Если нужен якорь с ПОЛНОСТЬЮ честными прогнозами тех же семейств — это val
2026-01-14: брать `work/preds/{model}_val.parquet` (писались val-фазной моделью
до ретрейна; таргет якоря полный, лежит в `anchor=2026-01-14.parquet`). Но там
формально другие веса (val-фазный близнец), не те, что в work/models.

## Санити (все 4/4 прошли)

Прогноз из весов на ТЕСТОВОМ якоре 2026-02-13 против
`work/preds/{model}_test.parquet` (его писал трейнер с этих же весов):

| модель | max\|Δlog1p\| test | max\|Δlog1p\| val | mean\|Δ\| val |
|---|---|---|---|
| twl_v7_s1337 | **0.0 (бит-в-бит)** | 1.81 | 0.286 |
| mlpziln_c42 | **0.0 (бит-в-бит)** | 1.60 | 0.143 |
| behavonly_s1337 | **0.0 (бит-в-бит)** | 1.44 | 0.292 |
| weak_ft_recency | **0.0 (бит-в-бит)** | 1.25 | 0.318 |

Порог < 1e-4 выполнен на test с запасом (точный 0 вкл. mlpziln на MPS): цепочка
«признаки якоря → веса → предсказание» воспроизводится точно, дрейфа признаков
нет. Расхождение на val — НЕ поломка, а следствие того, что `*_val.parquet`
писала val-фазная модель, а сохранены веса ретрейна (см. оговорку выше);
требование «совпасть с {model}_val.parquet» для этих весов невыполнимо
по построению, эквивалентная проверка — test.

## Как повторить / расширить

```
.venv/bin/python work/scripts/predict_at_anchor.py                # весь ростер, 3 якоря
.venv/bin/python work/scripts/predict_at_anchor.py --sanity       # + сверка val/test
.venv/bin/python work/scripts/predict_at_anchor.py \
    --models twl_v7_s7 --anchors 2025-11-05                       # любой другой якорь
```

Ограничения: якорь должен иметь собранные тиры признаков модели (для twl_v7 —
включая `anchor={ISO}.v7.parquet`); годятся любые `anchor=*.parquet` в
work/features. Полный таргет — только у якорей с датой ≤ 2026-01-14.
