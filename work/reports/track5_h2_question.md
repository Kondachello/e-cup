# Трек №5 → координатору: прежде чем хоронить H2, сверьте с текущим лучшим

Короткий вопрос по решению «H2-надстройки хоронятся». Возможно, оно правильное —
но тогда нужно одно число, которого у нас нет.

## H2_tfm_half — это ИЗМЕРЕНИЕ на лидерборде, не оценка

```
H1_applied.csv             1.6489955175   основа
H2_tfm_half   (масштаб 0.5) 1.6488111334   -0.0001844   8.4 шумовых единицы
H2_tfm        (масштаб 1.0) 1.6489392269   -0.0000563   2.6
H2_tfm_centered             1.6489663397   -0.0000292   1.3
```

Все три улучшили основу. На момент замера **1.6488111 был лучшим результатом
команды**. Это не валидационная оценка и не прикидка по формуле — три
потраченных сабмита.

Важно: устаревший пакет, из-за которого развалились мои числа по застоялости,
на это никак не влияет. Пакет использовался только чтобы посчитать форму
добавки; оценивал результат сам лидерборд.

## Асимметрия разрывов на H2 уже учтена — лидербордом

Аргумент против H2 — что вес, подобранный на валидации в режиме 31/31,
применяется к тесту в режиме 31/61. Он верен. Но в случае H2 поправку внёс сам
лидерборд:

```
масштаб 1.0  ->  1.6489392    перелёт
масштаб 0.5  ->  1.6488111    оптимум
```

Парабола по масштабу выпуклая, вершина s* = 0.521. То есть эмпирически
подобранная половина — и есть компенсация той самой асимметрии. Полномасштабный
вариант перелетел ровно так, как асимметрия и предсказывает.

## При этом библиотечный путь по вашему же замеру проигрывает

```
реопт библиотеки с tfm3    OOF 1.665830
эталон                     OOF 1.665764
                                +0.000066  хуже
```

Получается, хороним измеренно выигрывающий путь и оставляем измеренно
проигрывающий. Это может быть верно — но только при одном условии.

## Вопрос

**Какой сейчас лучший результат на лидерборде?**

* Если текущий лучший **лучше 1.6488111** — H2 просто устарел, вопрос снят,
  хороните.
* Если **хуже или его нет** — предлагаем не хоронить, а держать
  `submissions/H2_tfm_half.csv` живым кандидатом на одно из двух финальных
  решений. Срок 12:00 31 августа, а измеренный результат в руках — это
  страховка, которой больше ничего не заменит.

## Это временная мера, а не альтернатива библиотеке

Как только доедет `tfm3b` (фаза B, честные 31/31 с обеих сторон), асимметрия
исчезает и библиотечный путь должен заработать как надо — он лучше, там веса
подбираются по данным. H2 нужен только как мост до этого момента.

Сейчас на GPU идут сиды 2 и 3 фазы B, это порядка двух часов.

## Оговорка против нас

0.000184 — замер на публичной части. Перенос на приватную не гарантирован,
и для выбора финального решения это существенно. Но это верно для любого
нашего числа, включая OOF-оценки.
