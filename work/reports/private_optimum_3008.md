### 1.2 Явная формула

**Вклад осей.** Доктринный `gain()` (солвер :362) в развёрнутом виде:

```
G_π(b) = (2·b·cQ − b'·Q·b) / (2·F_SCALE)
       = Σ_i  q_i·b_i·(2·κ'_i − b_i) / (2·F_SCALE)        ← диагональ: «каппа и норма q»
       − Σ_{i≠j} Q_ij·b_i·b_j / (2·F_SCALE)               ← связь через Грам
       где  κ'_i = cQ_i/q_i  — приватная каппа оси, остаточная при дозах F7.
```

Диагональное слагаемое — это в точности `doctrine/transfer.gain(q, b, κ)` с приватной каппой
вместо публичной; при одной оси оптимум `b_i = κ'_i` совпадает с `dose_private`.

**Штраф.** `E[priv] = pub + k·PER` (валюта штаба, `finalists.md` §0). `k` — эффективное число
подогнанных направлений, по route D: `k = Σ_i (1.25 w_i − 0.25)`, применяется
**дифференциально** от якоря. Для дозового вектора `b`, собранного как `Σ_t w_t·lp_t` при
`Σ_t w_t = 1`, штраф **линеен по весам**:

```
k(b) = Σ_t w_t · k_t
```

и это не эвристика, а тождество: оптимизм линейного правила `b(cP) = A·cP + const` равен
`tr(A Σ_ε)/F_SCALE`, а смесь правил с фиксированными весами имеет `A = Σ w_t A_t`, значит
след складывается линейно. Отсюда же следует, что **уровень k сокращается**: замена
`k_t → k_t + c` даёт `Σ w_t k_t + c` при `Σw_t = 1`, то есть одинаковую добавку всем
кандидатам, включая F12.

**Две валюты (главная развилка доктрины).**

```
(B)  E_B[priv](b) = pub_alg(b) + k(b)·PER,        pub_alg(b) = √(F0² − 2 b·cP + b'Qb)
(A)  E_A[priv](b) = F0 − G_π(b)                   (усадка уже сделана, k не добавляется)
```

**Развилка:** `pub_alg → E[priv]` требует поправки на оптимизм подгонки. Валюта B оценивает
её как `k·PER`. Валюта A оценивает её как усадку `cP → cQ` — их разность равна в точности
`b·(cP − cQ)/F_SCALE`, то есть `doctrine/transfer.overstatement` просуммированный по осям.
**Это одна и та же величина, посчитанная двумя способами.** Складывать нельзя.
`kcalc_3008.md` §4.3 подходит к тому же выводу с другой стороны («называть весь множитель
`k` строго говоря нельзя»), а множитель ×2.39 из `eb_decomp` §5.1 — это ровно коэффициент,
которым две оценки приводятся друг к другу на Z-переходе; универсальной константой он не
является, что §4.2 `kcalc` и показал (×1.16 при капах).

Численно на 26 состояниях: `OV(b) = b·(cP−cQ)/F_SCALE` лежит в −3.1e-4…+1.7e-6, регрессия
`OV` на `k` даёт наклон 0.75·PER при R² = 0.49 — **две оценки коррелируют, но не равны**.
Поэтому ниже считаю обе и признаю кандидата надёжным только если он выигрывает в обеих.

**Гибрид (A + k), который просит формулировка задания,** тоже посчитан. Он воспроизводит
порядок трёх точек только при приорах групп G4/G5 (см. §2) и в §4–§6 приводится третьей

### 4.1 Свободный оптимум по всем 46 осям (верхняя граница достижимого)

В валюте B свободная задача **вырождена**: `max pub_alg(b)` при постоянном k — это ровно

### 4.2 Реализуемый оптимум: аффинная оболочка

Файл собирается как `Σ_t w_t·lp_t` при `Σ_t w_t = 1`; направления цепочки на диске
отсутствуют, поэтому достижимы ровно `b = Σ_t w_t·d_fin,t`. Доступных различных векторов **27**
(20 в 46-осевой системе + 7 расширенных), размерность аффинной оболочки **26**.

**Проблема безоговорочной аффинной оптимизации.** Если решать `max_w [G_pub(D'w) − PER·w·k]`
при `Σw=1` без ограничения на `w`, задача убегает: `‖w‖₁` растёт до 10⁵, `k(смесь)` уходит в
минус (−470), «выигрыш» −470 шума. Это артефакт: линейный член `w·k` не ограничен снизу вдоль
почти-нулевых направлений `D'`, а сама оптимизация `w` по данным — тоже подгонка, которую
линейный учёт `Σw_t k_t` не оплачивает. **Все такие решения отвергнуты.** Приводится
ограниченная задача.

**Выпуклая оболочка** (`w ≥ 0`, `Σw = 1`) — безусловно безопасная:

### 4б.2 Почему валюта B не оптимизируется по дозам, а валюта A — оптимизируется

**Это ключевой пункт, и он не декоративный.** По доктрине `k` зависит ТОЛЬКО от приора
(`Λ` и `cQ`), но не от доз и не от γ — `kcalc` §0 п.1 формулирует это как обязательное
свойство: в группе G0 живут γ = 0.00…0.10, и `k` у них обязано совпадать. Тогда при
фиксированном приоре `min_b [pub_alg(b) + k·PER]` = `max_b G_pub(b)`, оптимум `b = Q⁻¹cP` —
**чистая подгонка паблика, прямо запрещённая доктриной**. Валюта B ранжирует РЕЦЕПТЫ, но
целевой функцией по `b` быть не может.

Валюта A этой болезни не имеет: анти-переобучение сидит внутри `cQ` (усадка), и
`max_b G_π(b)` даёт конечный, осмысленный `b* = Q⁻¹cQ_π`.

Практический вывод: **оптимизирую по семейству доктринных решений
`b(π, γ, капы) = (Q + Λ_π + γ·diag Q)⁻¹ cQ_π` с обнулёнными осями капов**, оцениваю КАЖДОГО
кандидата в обеих валютах и беру минимакс. γ остаётся неоплаченной ручкой — поэтому головной
кандидат берётся при γ = 0.08, ровно как у F12, чтобы арбитража на ней не было.

конвенции тождественны (это и есть причина, по которой кампания расхождения не замечала);
расходятся они ровно на смене носителя. В §4 использована вторая, консервативная.
