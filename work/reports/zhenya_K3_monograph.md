## 0. Что это за документ

Кампания породила около десятка утверждений, которые называли «законами». Часть
из них верна, часть я отзывал, часть верна с оговорками, о которых легко забыть.
Здесь они сведены в одну систему: что из чего следует, где допущение, где замер.

Порядок разделов — логический, а не хронологический: сначала геометрия задачи,
из неё алгебра, из алгебры выборочная теория, из неё дозировка, из дозировки
ранговая задача. Раздел 8 — список моих собственных ошибок; он не приложение,
а часть теории, потому что каждая ошибка показала границу применимости.

## 1. Геометрия: метрика как квадратичная форма

Метрика соревнования — RMSLE. В пространстве `lp = log1p(прогноз)` она
**евклидова**: для набора юзеров S

```
f_S²(lp) = mean_S( (lp − t)² ),    t = log1p(факт)
```

Отсюда всё остальное. Три немедленных следствия:

**1.1. Смесь двух файлов — парабола.** Для `lp = lp_A + b·h`:

```
f²(b) = F0² − 2b·c + b²·q,     c = mean(h·(t − lp_A)),  q = mean(h²)
```

Оптимум `b* = c/q ≡ κ`, выигрыш в оптимуме `κ²q/(2F0)` в единицах скора.
**Это точное тождество, а не аппроксимация.**

**1.2. `c` линеен по направлению.** Для `D = Σaᵢhᵢ`:

```
c_D = Σ aᵢ cᵢ = Σ aᵢ κᵢ qᵢ
```

Грам не нужен. Это тождество спасло разбор R9 (§5.4): поосное сложение `b²q`
неверно, а линейность `c` верна всегда.

**1.3. Спан замеренного.** Если известны публичные скоры `k` файлов, то для
любой их аффинной комбинации публичный скор вычисляется **точно** — платформа
детерминирована, а `f²` квадратична. Это основа предсказателя (`predict_lb.py`,
замера) и паблик-арбитража SHOW.

*Проверка:* попадания расчёт↔факт по всей серии F1–F7 — средний промах 2e-6
при типичном шаге 0.0005, то есть 0.4 % величины шага.

## 2. Закон переноса: κ как проекция

**Определение.** `κ` — не выигрыш, а **коэффициент**: доля применённого шага,
которая оказывается оптимальной. `κ = c/q`. Выигрыш `κ²q/(2F0)`.

**Наблюдение кампании (5 подтверждений):** предиктора `κ` из валидационно
наблюдаемых величин **не существует**. Валидационный выигрыш оси не предсказывает
её `κ` на тесте.

Самый чистый случай — erafix (mdl_kyanit): валидационный эффект был **реален**
(−0.000122, t = −3.26, знак 7 из 8 парных сидов), перенос — **ноль**
(κ = −0.009 ± 0.144).

**Теорема о переобучении приора (обобщение G §1.4).** Классовые приоры
проваливались пять раз подряд. Причина не в «мало точек», а количественная:
классовый приор есть оценка `τ` по подвыборке размера `m`. Выборочная ошибка
оценки `τ` по `m` точкам порядка `τ/√(2m)`. При `τ = 0.196` и `m = 3` это 0.08,
то есть заявленная точность «класс R = 0.55 ± 0.05» была завышена вчетверо.

**Следствие:** приор всегда оценивать по максимально широкой однородной
популяции. Поле `cls` в реестре — метка провенанса, в дозировку не подставляется
никогда.

*Скрипты:* `n1_prior.py`, `g8_transfer.py`.

## 3. Выборочная теория (ядро)

Здесь единственный по-настоящему проверенный экспериментом закон кампании.

### 3.1. Устройство разбиения

Тест — 250 000 юзеров, публика `P` — 50 000, приват `Q` — 200 000, `Q = T \ P`.
Доля `f = 0.2`. Публика **не независимая выборка**, а подмножество.

### 3.2. Анти-корреляция публика↔приват

Из `c_T = f·c_P + (1−f)·c_Q` тождественно:

```
κ_Q = κ_T − (f/(1−f))·(κ_P − κ_T) = κ_T − 0.25·ε,     ε ≡ κ_P − κ_T
```

**Ошибка публичного замера и приватный остаток антикоррелированы.** Это не
модель, а арифметика разбиения.

**Проверено прямым экспериментом** (`a1_verify_wp.py`): настоящие lp-векторы,
настоящий таргет, 800 разрезов 250k на 50k/200k, четыре направления разного
масштаба. Наклон `d(κ_Q − κ_T)/dε`:

| направление | q | наклон факт | теория | корреляция |
|---|---|---|---|---|
| tfm4 | 0.00061 | −0.2503 | −0.2500 | −0.9999 |
| gru | 0.00165 | −0.2499 | −0.2500 | −0.9997 |
| ridge | 0.00280 | −0.2588 | −0.2500 | −0.9961 |
| shade | 0.00007 | −0.2500 | −0.2500 | −0.9993 |

### 3.3. Стандартная ошибка κ

```
σ_κ = g · F0/√(n_пуб·q) · √(1 − f)
```

Два множителя, оба выведены и оба нужны:

- **√(1−f) = 0.894** — конечная популяция. При `n_пуб → N` ошибка обязана
  обращаться в ноль; голая формула этого не даёт.
- **`g`** — гетероскедастичность. Вывод принимал `σ_u² ≈ q·F0²`, то есть
  направление независимым от остатка. Это неверно, и **`g` зависит от оси**.

### 3.4. Локальная σ_u — замкнутая форма для сегментных осей

Для среднесохраняющего индикатора сегмента `S` с долей `p`:

```
g² = ((1−p)·A + p·B) / (p·A + (1−p)·B),    A = MSE внутри S,  B = снаружи
```

Малый сегмент: `g² → A/B`. **`g` определяется долей ошибки, которую несёт
сегмент**, и считается локально на валидации — без единой посылки.

Проверено на шести сегментах: формула совпадает с прямым `sd(h·r)/(F0√q)` до
третьего знака.

| ось | g |
|---|---|
| ядро recency 15–90 | 1.052 |
| спящие 91–365 | 0.928 |
| никогда не покупавшие | **0.688** |
| спящие-браузеры | **0.671** |
| топ-5 % активных | 0.805 |

**Диапазон по типам осей:**

| тип | g |
|---|---|
| разность моделей / членов бленда | ≈ 1.15 (замерено 1.12–1.62) |
| сегментная индикаторная | 0.67–1.05, по формуле выше |

**Общее правило: `σ_u` считать локально как `sd(h·(t − lp))`. `F0√q` —
аппроксимация, верная лишь при независимости направления от остатка.**

*Скрипты:* `a1_verify_wp.py`, `a2_sigma_factor.py`, `b1_sigma_local.py`.

## 4. Теория дозы

### 4.1. Приватная усадка

Приор `κ_T ~ N(μ, τ²)`, замер `κ_P = κ_T + ε`, `sd(ε) = σ`. Тогда

```
E[κ_Q | κ_P] = μ + w_p·(κ_P − μ),      w_p = 1.25·w − 0.25,   w = τ²/(τ²+σ²)
sd[κ_Q | κ_P] = 1.25·τ·√(1−w)
```

Три порога, все содержательные:

| условие | смысл |
|---|---|
| `w > 1/3` | публичная доза даёт положительный приватный EV |
| `w = 1/3` | публичная доза даёт **ровно ноль** |
| `w = 0.20` | замер **бесполезен**: `w_p = 0`, доза равна приору |
| `w < 0.20` | замер **анти-информативен**: двигать дозу против чтения |

При `μ = 0`: `E[приват при дозе wκ̂] = ½κ̂²·w·(3w − 1)`.

### 4.2. Приоры берутся по своей популяции

Три разных приора, смешивать нельзя:

| популяция | μ | τ | почему |
|---|---|---|---|
| предложенные оси (реестр) | 0.309 | 0.196 | несёт частоту попаданий предлагателя |
| сегментное семейство P (32 зонда) | 0.026 | 0.121 | однородная конструкция, свой уровень |
| оси Z-разложения (20 пар) | −0.011 | 0.0148 | **исчерпывающее** разложение, предлагателя нет |

**Для осей-разностей внутри уже дозированного оптимума μ = 0 строго.** Условие
первого порядка даёт `c_P(h) = 0` тождественно для любого `h` из подпространства,
по которому базу оптимизировали: замер вернёт ноль по построению.

`τ` для такого набора — эмпирический байес по нему самому:
`τ² = max(0, Var(κ̂) − ⟨σ²⟩)`. Если разброс замеров не превышает их собственного
шума, `τ = 0`, и правильная доза каждой оси — ровно `μ`, независимо от чтения.

**Приор считать по ВСЕМУ семейству, включая нули.** Подгонка по одним «живым»
осям — ошибка отбора: на живых восьми `μ` выходит +0.138 против +0.026 по всем 32.

### 4.3. Ценность зонда — замкнутая форма

```
V(q, τ) = (τ²q − 0.25c)² / ((τ²q + c)·2F0),      c = 0.8·F0²/n_пуб = 4.34e-5
```

**Зонд осмыслен только при `τ²q > 0.25c`.** Точный критерий вместо интуиции.

| семейство | τ | q=0.003 | q=0.01 | q=0.02 | q=0.05 |
|---|---|---|---|---|---|
| новая модельная ось | 0.196 | 0.95 | 4.50 | 9.75 | 25.6 |
| сегментная когорта | 0.086 | 0.03 | 0.47 | 1.36 | 4.30 |
| ось Z-разложения | 0.0148 | 0.00 | 0.00 | 0.00 | 0.00 |

(в шумах приватного EV). **Правило 4×-шага** получает здесь точное обоснование:
`V` растёт по `q` почти линейно в рабочей зоне.

### 4.4. Переоценка неустранима

```
переоценка(ось) = q·b·(κ_P − E[κ_Q])/F0
```

**Её нельзя обнулить, пока мы дозируем по публичной обратной связи.** Даже при
идеальной дозе `b = E[κ_Q]` она равна `q·b·(κ_P − b)/F0 > 0`, потому что `κ_P`
всегда дальше от приора, чем `E[κ_Q]`. **Усадка минимизирует потерю к оракулу,
а не переоценку.**

Безусловная цена одного подогнанного направления:

```
2.5·σ²·q/(2F0) = 1.25·(1−f)·F0/n_пуб = 3.29e-5 = 1.5 шума
```

**Не зависит ни от `q`, ни от силы сигнала.** Накопленная по кампании:
**0.000764…0.001028** (35–47 шумов).

*Скрипты:* `n5_final.py`, `n11_segprior.py`, `n20_slots.py`, `a4_honesty_fix.py`.

## 5. Слип и цена подгонки

### 5.1. Тождество слипа

`δ(x) ≡ mean₂₅₀ₖ(x) − mean_публика(x)`. Для элемента спана
`lp = lp_a + c₀ + Σcᵢdᵢ`:

```
слип ≡ факт − расчёт = δ(u),
u = Σᵢ cᵢ dᵢ² − (c₀ + Σᵢ cᵢ dᵢ)² − 2c₀·lp_a
```

**Таргет сокращается полностью.** Слип не зависит от того, каким окажется
тестовый таргет — только от геометрии lp и от того, какие 50k попали в публику.

**Теорема.** При фиксированном `c` слип имеет нулевое среднее. Отсюда: обычные
дозированные файлы попадают в расчёт с точностью 5e-7 — это не везение.
Слип возникает **только когда `c` подбирается под замеры**.

### 5.2. Эмпирический закон

Шесть точек SHOW (Σ|c| = 7, 19, 27, 37, 146, 279):

```
слип = 1.042e-5 · Σ|c|        R² = 0.946
```

Ниже `Σ|c| ≈ 20` слип неотличим от нуля: систематический член (~1e-4) тонет
в собственном разбросе (1.2–2.1e-4). Именно этим объясняются отрицательные
слипы SHOW9/SHOW10, а **не** заякориванием базиса — эта гипотеза была проверена
прямым тестом и опровергнута (`n16_slip_anchor.py`).

**Оговорка:** закон описателен. При `c → 0` слип обязан обращаться в ноль,
линейная форма этого не даёт.

**Устранение:** слип обращается в ноль тождественно, если `mean(lp²)`
восстанавливать по публике, а не брать по 250k — вся его причина в этом
рассогласовании.

*Скрипты:* `n4_curse_exact.py`, `n17_sliplaw5.py`, `n16_slip_anchor.py`.

## 6. Доктрина резерва: непохожесть, а не качество

Три независимых подтверждения одного принципа.

**6.1. Члены бленда.** kevf3 (событийный трансформер + таблица) пришёл к
корреляции 0.9978 с блендом, tfm4 (дневная модель) — 0.9980. **Разные
архитектуры, читающие те же 176 признаков, приходят в одну точку.** Вклад обоих
как новых членов — шум (joint_gain 0.000007 и 0.000011 при пороге 0.000044).

Контрпример в той же таблице: `tfm4_tabless` при корреляции **0.9823** и соло-скоре
**на две сотых хуже** стоит 0.000434 — в семнадцать раз дороже kevf3.

| член | корр с блендом | 1 − r² |
|---|---|---|
| kevf3avg | 0.9978 | 0.0044 |
| tfm4 | 0.9980 | 0.0040 |
| **tfm4_tabless** | **0.9823** | **0.0351** |

**6.2. Финальная пара.** Второй финалист выбирается по непохожести, а не по
близости к первому (Часть E).

**6.3. Ранговая лотерея.** Передоз своих же осей не создаёт независимой
дисперсии: варианты скоррелированы на 0.93–1.00 (§7).

**Общий закон: резерв измеряется не качеством кандидата, а его непохожестью
на то, что уже есть.** Правило приёмки должно смотреть на `1 − r²` первым,
а на соло-скор — вторым.

## 7. Ранговая теория

Зачёт ранговый, значит максимизировать надо `P(топ-k)`, а не `E[скор]`. При
отставании правильно покупать дисперсию — но покупать её нечем.

**Квадратичная лемма.** При `E(b) = E* − a(b − b*)²` и `sd(b) = s·b` максимум
`(E(b) − D)/sd(b)` достигается при

```
b_ранг = √(b*² + D/a) > b*
```

**Внутренний оптимум передоза существует** (у нас `s ≈ 1.5`), но выигрыш
ограничен: +0.37 п.п. `P(топ-3)` при пороге принятия 5 п.п.

**Лотерею убивает корреляция, а не квадратичность.** Разные дозы одних и тех же
осей дают **идеально** скоррелированные исходы (ρ = 1.00); смена состава осей
даёт ρ = 0.93. Даже гипотетический идеально независимый билет (ρ = 0) дал бы
+3.8 п.п. в оптимистическом мире и ноль в пессимистическом.

**Модель поля.** `pop = паблик + bias(n) + ε`, где `bias` калибруется по
собственному разрыву «витрина → честный приват». Ранг оказался почти целиком
функцией ненаблюдаемого: 2 / 5 / 8 в трёх мирах на одном и том же нашем файле.


## 8. Ошибки кампании и как они были пойманы

Раздел не декоративный: каждая ошибка очертила границу применимости закона.

| # | утверждение | как поймано | граница, которую показало |
|---|---|---|---|
| 1 | «бленд на потолке 1.68» | ревью: параметры из одного окна, sd из другого | нельзя смешивать окна в одном расчёте |
| 3 | `s* = 0.75` для R9 | прямые 20 пар Саши: `τ_z = 0.0148`, не 0.078 | **приор берётся по своей популяции** (§4.2) |
| 5 | blanket `σ ×1.15` | замер на сегментных осях: 0.67–1.05 | `g` поосный, а не общий (§3.4) |
| 6 | «передоз заведомо проигрышен» | собственная же таблица: `s=1.5` даёт +0.37 п.п. | внутренний оптимум существует (§7) |

Общее у трёх из шести (№3, №4, №5) — **обобщение с одной популяции на другую**.
Это главный системный дефект моей работы за кампанию, и он же — содержание
§4.2, самого практически ценного правила теории.

Отдельно: №3 и №5 были пойманы **в течение суток** после публикации, потому что
результаты сверялись с чужими прямыми замерами. №1 и №4 держались дольше —
их никто не мог проверить, кроме меня самого.
