**Класс «алгебраические κ».** Точки, где κ получена не одним зондом против базы,
а параболой через ≥2 дозы (T-серия), помечаю отдельно. Саша прав: у них σ измерения
**ровно ноль** — платформа детерминирована, парабола точна для публичного скора.
Но и у зондовых точек σ измерения тоже ноль по той же причине. Разницы в σ между
классами нет: **вся σ у всех точек реестра — это выборочный зазор публика→генеральная**,
и он считается по закону, а не по способу получения κ. Класс поэтому — только метка
провенанса; на дозировку он не влияет. Практическая разница одна: алгебраическая
точка стоила две попытки вместо одной, зато даёт заодно проверку самой параболы.

## 2. Приор для микро-осей: формализация

Саша применил «приор 0 для осей разложения, 0.333 для настоящих новых осей» и назвал
это импровизацией. Импровизация **верна по среднему и опасна по разбросу**.

### 2.1. Что на самом деле означает реестровый приор

N(0.309, 0.196²) — распределение κ по осям, которые **кто-то предложил**. В нём
зашита частота попаданий предлагателя: положительное среднее 0.309 берётся не из
физики, а из того, что люди предлагают оси, в которые верят. Это приор над
**предложенными** осями.

Разложение предложенным не является — оно **исчерпывающее**. У него нет предлагателя,
поэтому оно не наследует ни среднего, ни разброса.

### 2.2. (а) Оси-разности внутри уже собранного оптимума

**Среднее: строго 0.** Если база выбрана минимизацией публичного скора по подпространству
V, то условие первого порядка даёт c_P(h) = 0 **тождественно** для любого h ∈ V:
замер вернёт ноль по построению и не несёт информации. Если база дозирована лишь
вдоль родительского направления D = Σaᵢhᵢ, компоненты связаны тождеством
Σ aᵢ κᵢ qᵢ = κ_D q_D — совокупный сигнал уже собран дозой родителя. Осмысленно
дозировать только **отклонение** компоненты от родительского паттерна, а у отклонения
среднее равно нулю по определению отклонения. Ненулевое априорное среднее означало бы,
что оптимизатор систематически ошибается в известную сторону — противоречие.

**Разброс: τ_z оценивать эмпирическим байесом по самому набору разложения.**
ML по 20 Z-точкам: максимизировать Σ log N(κ̂ᵢ | μ, τ² + σᵢ²) по (μ, τ). Две строки
кода и одна из главных цифр перед заморозкой (раздел 3.4).

Формально τ_z² = max(0, Var(κ̂) − ⟨σᵢ²⟩). **Если разброс замеров не превышает
собственного шума замеров, τ_z = 0**, и тогда правильная доза каждой оси разложения —
ровно μ_z, то есть ноль, независимо от того, что показал замер. Все различия между
осями в этом случае — шум публики целиком.

### 2.3. (б) Сконструированные направления (джойнт)

Своего приора у джойнта нет. Он — линейная комбинация осей с уже оценёнными
апостериорами, и его κ **индуцируется**: для D = Σaᵢhᵢ

```
κ_D = Σ aᵢ κᵢ qᵢ / q_D,    Var(κ_D) = Σ aᵢ² qᵢ² Var(κᵢ) / q_D²
```

Отдельный зонд джойнта не даёт ничего, кроме проверки арифметики, **если веса aᵢ
фиксированы заранее**. Если веса подбирались под публичные замеры — см. 2.4.

### 2.4. Winner's curse для направлений, построенных ПО ПАБЛИК-ЗАМЕРАМ

**Тождество.** Пусть δ(x) = mean₂₅₀ₖ(x) − mean_публика(x). Предсказатель восстанавливает
ψ из **публичных** скоров, а mean(lp²) считает по **250k**. Для любого элемента спана
lp = lp_a + c₀ + Σcᵢdᵢ (dᵢ = lpᵢ − lp_a):

```
слип ≡ факт − расчёт = δ(u),
u = Σᵢ cᵢ dᵢ² − (c₀ + Σᵢ cᵢ dᵢ)² − 2c₀·lp_a
```

**Таргет сокращается полностью.** Слип не зависит от того, каким окажется тестовый
таргет — только от геометрии lp-векторов и от того, какие 50k попали в публику.
Два следствия:

1. **При ФИКСИРОВАННОМ c слип имеет нулевое среднее.** Поэтому обычные дозированные
   файлы попадают в расчёт с точностью 5e-7 — это не везение, а теорема.
2. **Слип возникает ровно тогда, когда c ПОДБИРАЕТСЯ под замеры.** Оптимизатор видит
   ψ̂ = ψ_публика + Δ/2, где Δᵢ = δ(lpᵢ² − lp_a²), и эксплуатирует Δ.

**Замер.** 80 розыгрышей раскола 50k/250k на настоящей геометрии 31 файла
(`n4_curse_exact.py`):

| 1e-2 | 1.5 | +0.000071 | 0.000124 | +0.000001 |

Колонка «при фиксированном c» — контроль: там ноль, как и должно быть по пункту 1.

  что вся его причина в этом рассогласовании. Для файлов внутри спана это делается

## 3. Приватная EV-доза финала

### 3.1. Асимметрия, которую мы до сих пор не учитывали

Публика — **не независимая выборка**, а подмножество тех же 250k. Приват — её
**дополнение**. Значит ошибка публичного замера и приватный остаток **антикоррелированы**,
и это меняет формулу дозы.

Пусть κ_T — истинная каппа на всех 250k, κ_T ~ N(μ, τ²). Замер даёт κ_P = κ_T + ε,
sd(ε) = σ. Тогда **тождественно**, из того что приват = 250k минус публика:

```
κ_Q = κ_T − (f/(1−f))·ε = κ_T − 0.25·ε,        f = n_пуб/N = 0.2
```

Апостериор:

```
E[κ_Q | κ_P] = μ + w_p·(κ_P − μ),     w_p = 1.25·w − 0.25,   w = τ²/(τ²+σ²)
sd[κ_Q | κ_P] = 1.25·τ·√(1−w)
```

Проверки: при w = 1 (идеальный замер) w_p = 1. При w = 0 получается w_p = −0.25 —
и это правильно: если замер был чистым шумом, приват получил его зеркало, и двигаться
надо **против** чтения.

**Три порога:**

| условие | что значит |
|---|---|
| w > 1/3 | публичная доза даёт положительный приватный EV |
| w = 1/3 | публичная доза даёт **ровно ноль** на привате |
| w = 0.20 | замер **бесполезен**: w_p = 0, доза = приор |
| w < 0.20 | замер **анти-информативен** |

При μ = 0 (оси разложения) публичная доза w·κ̂ даёт E[приват] = ½·κ̂²·w·(3w − 1) —
отрицательный при w < 1/3. Самый жёсткий результат раздела.

лежит в [0.956, 0.994], при τ = 0.05 — 0.913. Значение 0.95 отстоит от края этого
диапазона не более чем на 0.045, теряет при этом ≤ 2% урожая и при τ = 0.05 экономит
8% дисперсии.

скора T3: **ожидание +0.00035 … +0.00050, 95% интервал примерно [+0.00003, +0.00088]**.

### 3.4. Что решает всё, и чего у меня нет

Вся таблица 3.3 висит на **τ_z** — разбросе истинных κ по осям разложения. Мне нужны
20 пар **(κ̂ᵢ, qᵢ)** Z-разложения. Из них ML за одну строку даёт (μ_z, τ_z), и вместо
шести сценариев останется один ответ.

### Три уточнения, которые важнее самого вердикта

**4.1. Виноваты не оси, а СЫРЫЕ дозы.** Посмотрите на знаки. У всех осей с усадкой (R8,
JS-дозы U-семейства, mdl_gypsum) переоценка **нулевая или отрицательная**: усадка не просто
снижает риск, она делает файл честнее публичного чтения.

**4.2. Пересматривать применённые дозы поздно, но не бессмысленно.** Оси mdl_amber (w = 0.37,
доза 0.803 при приватном оптимуме 0.413) и mdl_halite (0.756 против 0.403) передозированы
вдвое. **Самая дешёвая работа, которая у нас осталась, —
не искать новое, а поправить дозы старого.**

**4.3. SHOW4–SHOW6 в решение не входят, но как данные они дороже, чем кажется.**
Они дали четвёртую и пятую точки для закона слипа (2.4), и именно они позволили
посчитать его без единого подгоночного коэффициента. Если будут ещё SHOW-запуски —
пусть меняют **ридж при том же спане**: это самый информативный разрез, и у меня по
нему только расчёт, ни одного факта.
