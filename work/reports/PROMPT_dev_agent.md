## Новая система координат (заменяет старые правила приёмки)

1. Формулой `вклад ≈ 7.1·запас²` НЕ пользоваться: у сильных моделей (sm/sb → 1)
   вклад почти линеен по запасу. Приёмка — только прямым замером набора
   (`work/scripts/joint_gain.py`) или точной алгеброй пары.
2. Приёмка ПО НАБОРУ, не по одной модели: запас не складывается, слабый одиночка
   может быть плюсом в паре (пример: hz_v1_surv).
3. Эталон всех замеров — колонка `blend` пакета `work/preds_pack` (1.666395),
   калибровка честная кросс-фит. Порог приёмки набора: +0.0003.
4. Искать сильные модели с любым положительным запасом, а не слабые с большим.
