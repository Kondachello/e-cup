## Новая система координат (заменяет старые правила приёмки)

1. Формулой `вклад ≈ 7.1·запас²` НЕ пользоваться: у сильных моделей (sm/sb → 1)
   вклад почти линеен по запасу. Приёмка — только прямым замером набора
   (`work/scripts/joint_gain.py`) или точной алгеброй пары.
   ПОДТВЕРЖДЕНО НЕЗАВИСИМО (20.08, прямая пересборка бленда наименьшими квадратами):
   исходная формула объясняет **9%** разброса, линейная — **99%**, отношение факт/запас
   держится около 0.035-0.052. Формула занижает вклад в 3-8 раз и тем сильнее, чем
   меньше запас, поэтому она отбраковывала не тех.
   ЛОВУШКА при любой такой проверке: в `work/preds` лежат модели эпохи ДО зазора
   30 дней, их валидационный скор завышен на 0.05-0.10 (встречаются скоры 1.4968 при
   бленде 1.6664 — для честной одиночной модели это невозможно). Если их не отсеять,
   они вытянут ЛЮБУЮ подгонку и обе формы дадут mdl_flint≈0.88. Честный пул — колонки
   `work/preds_pack/val_preds.parquet`.
2. Приёмка ПО НАБОРУ, не по одной модели: запас не складывается, слабый одиночка
   может быть плюсом в паре (пример: hz_v1_surv).
3. Эталон всех замеров — колонка `blend` пакета `work/preds_pack` (1.666395),
   калибровка честная кросс-фит. Порог приёмки набора: +0.0003.
4. Искать сильные модели с любым положительным запасом, а не слабые с большим.
