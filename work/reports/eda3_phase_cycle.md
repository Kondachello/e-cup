# eda3: линза «фаза покупательского цикла» — итог: кандидатов НЕТ

Дата: 2026-08-22. Эталон: `blend` из work/preds_pack/val_preds.parquet (RMSE 1.665647),
остаток e = log1p(target) − blend, N=250000. История: train.parquet до якоря 2026-01-14
(день 378). Порог интереса по вкладу: dRMSE ≈ 0.0003.

Скрипты: eda3_phase_cycle_stats.py (агрегация), eda3_phase_cycle_analyze.py (бины фазы),
eda3_phase_cycle_oof.py (OOF/концентрация/плацебо/n_expected), eda3_phase_cycle_cadence.py.
Промежуточный parquet — в scratchpad сессии (не в репо).

## Определения

- Заказный день: event_date с to_ord>0 (4 319 852 строк до якоря; 216 058 юзеров с ≥1).
- Период P = медиана межзаказных интервалов; cv = ord_gap_std/mean; rec = якорь − последний заказ.
- Прогресс u = rec/P; wrap-фаза = u mod 1 (пилообразная, НЕ признак; в 203 признаках есть
  rec_order, ord_gap_mean/std/min/max, rec_over_gap=rec/(mean+1); медианы и wrap-фазы нет).

## Замер 1 (главный вопрос линзы): резкая wrap-фаза у высокорегулярных — МЕРТВА

Остаток по 5 бинам (u mod 1), только u≤3:

- cv≤0.5, n≥5 (n=1455): все |t|≤1.49; oracle dMSE=0.000036 → dRMSE=0.000011
- cv≤0.8, n≥5 (n=18655): все |t|≤0.67; dRMSE=0.000005
- cv≤0.5, n≥8 (n=320): все |t|≤1.06; dRMSE=0.000010

Практический пробник оболочки НИЧЕГО не пропускает: резкой периодической структуры в
остатке нет даже in-sample оракулом, на два порядка ниже порога. Согласуется с ранее
закрытым (KNOWLEDGE:389): выравнивание матрицы по фазе хуже календаря (0.000732 vs
0.001188), гистограмма интервалов мертва (0.000055).

## Замер 2: прогресс u=rec/P по срезам — единственный «сигнал», убит OOF и китами

Лучший из четырёх срезов (выбор среза = подгонка!) P∈[14,60], cv≤0.6, n=3067:
бины u дают +0.21 (t=2.5) / −0.33 (t=−3.6) / … / +0.23 (t=3.2), oracle dRMSE=0.000153.

Честная проверка (2-фолд по юзерам, 20 повторов, поправка биновым средним фолда A на B):

- OOF dMSE = 0.000165 ± 0.000121 → dRMSE = 0.000049 — в 6 раз ниже порога;
- концентрация: top1% юзеров несёт 156% суммарного выигрыша (остальные в минусе),
  top0.1% — 21% — чистые киты, класс «выигрыш в китах не переносится» (закрыт LB);
- плацебо (перестановка u, 30 повторов): mean −0.000197, max +0.000001 — сигнал есть,
  но микроскопический и китовый.

Механизм и не обещал большего: u почти совпадает с признаком rec_over_gap (гладкая
часть в оболочке), новое — только медиана вместо среднего и выбор среза.

## Замер 3: n_expected (число плановых заказов, попадающих в окно 30д) — ШУМ

nexp = floor((rec+30)/P) − floor(rec/P) — резкая целочисленная композиция (rec,P),
формально вне признаков. По трём срезам структуры нет, знак скачет:

- P[14,60] cv≤0.6: nexp=0/1/2 → +0.00/+0.05/+0.16 (t≤1.75)
- P[14,90] cv≤0.8: nexp=2 → −0.03 (t=−0.9); nexp=3 → +0.99 (t=4.2), но n=51 —
  вклад ≤0.00006 dRMSE и это китовая ячейка
- P[20,120] cv≤1.0: nexp=0/1/2 → +0.00/−0.01/+0.00 (все |t|≤0.7)

## Замер 4: тренд каденции gap_last/P (gap_last НЕ входит в 203 признака) — МЁРТВ

6 бинов r=gap_last/P на всех n≥5 (n=161106): mean_e в пределах ±0.019, oracle
dRMSE=0.000033. Двойной контроль (rec-бин × r≤1/r>1): максимум расхождения 0.06
лог-единицы (rec-бин4, t=−3.0), вклад такого масштаба ≤0.00004 dRMSE. Ничего.

## Вердикт

Кандидатов-векторов НЕТ. Линза закрыта четырьмя замерами с четырёх сторон
(wrap-фаза, прогресс, плановые заказы в окне, тренд каденции): бленд уже исчерпал
фазовую информацию с точностью лучше 0.00005 dRMSE, а «резкая периодичность,
невидимая гладким пробникам» в остатке отсутствует физически, потому что
высокорегулярных юзеров 0.7% и типичный cv≈1.05. Не переоткрывать: любые
сегментные поправки по (P, cv, u) — это класс «сегменты/линейные корректоры»,
закрытый 23 LB-зондами, и киты.
