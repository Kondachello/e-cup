# `doctrine` — библиотека управления неопределённостью

Сжатая монография в коде. Каждый закон — функция, каждый закон — тест на
историческом замере. Полные выводы: `work/reports/zhenya_K3_monograph.md`.

```
python work/doctrine/tests/test_doctrine.py     # 20 тестов на исторических замерах
```

## Задача, которую решает библиотека

Мы оптимизируем модель под **скрытую генеральную совокупность**, а обратную связь
получаем по **видимой выборке** (20 % пользователей). Улучшение, найденное на
выборке, переносится **частично**, и доля переноса подлежит оценке, а не
предположению. Библиотека — про то, как эту долю оценивать и как под неё дозировать.

## Пять формул, на которых всё держится

**1. Парабола смеси.** Метрика евклидова в `lp = log1p(прогноз)`, поэтому

```
S²(b) = F0² − 2b·c + b²·q,    κ = c/q,    выигрыш = κ²q/(2F0)
```

`c` **линеен** по направлению: `c_D = Σaᵢκᵢqᵢ`. Грам не нужен. Поосное сложение
`b²q` — неверно, линейность `c` — верна всегда.

**2. Приватная усадка.** Приват есть **дополнение** видимой выборки, поэтому
ошибка замера и приватный остаток **антикоррелированы**:

```
w_p = w/(1−f) − f/(1−f) = 1.25·w − 0.25      (f = 0.2)
E[κ_Q | κ_P] = μ + w_p·(κ_P − μ)
```

Проверено прямым замером: наклон **−0.2500** при теории −0.2500, корреляция
−0.9999 на 800 разрезах.

Три порога: `w > 1/3` — публичная доза даёт положительный приватный EV;
`w = 0.20` — замер бесполезен; `w < 0.20` — замер **анти-информативен**.

**3. Стандартная ошибка.**

```
σ_κ = g · F0/√(n_вид·q) · √(1 − n_вид/N)
```

`g` — **поосный** множитель гетероскедастичности. Для индикаторных сегментов
замкнутая форма через долю ошибки:

```
g² = ((1−p)·A + p·B) / (p·A + (1−p)·B)      A = MSE внутри, B = снаружи
```

Диапазон на наших осях **0.67…1.05**. Константы нет: тихий сегмент меряется
**точнее** формулы, шумный — грубее.

**4. Ценность зонда.**

```
V(q, τ) = (τ²q − 0.25c)² / ((τ²q + c)·2F0),    c = (1−f)·F0²/n_вид
```

Зонд осмыслен **только при `τ²q > 0.25c`**. Отсюда правило крупного шага.

**5. Слип.** `δ(x) = mean_все(x) − mean_вид(x)`; для элемента спана

```
слип = δ(u),   u = Σcᵢdᵢ² − (c₀ + Σcᵢdᵢ)² − 2c₀·lp_a
```

**Таргет сокращается.** При фиксированном `c` среднее слипа **ноль** — поэтому
дозированные файлы попадают в расчёт с точностью 5e-7. Слип возникает только
когда `c` подбирается под замеры.

## Три правила, которые дороже формул

**Приор берётся по своей популяции.** Три из шести ошибок кампании — обобщение
приора с одной популяции на другую. В `dose.py` три разных приора, и они
намеренно разведены константами:

```python
PRIOR_PROPOSED = (0.309, 0.196)   # предложенные оси
PRIOR_SEGMENT  = (0.026, 0.121)   # сегментное семейство
PRIOR_DECOMP   = (0.0,   0.0148)  # оси разложения: μ = 0 СТРОГО
```

**Приор считается по всему семейству, включая нули.** Подгонка по одним «живым»
осям — ошибка отбора: на живых восьми μ = +0.138 против +0.026 по всем 32.

**Переоценку нельзя обнулить.** Пока дозируем по обратной связи с выборки,
переоценка положительна даже при идеальной дозе. Усадка минимизирует **потерю
к оракулу**, а не переоценку. Цена одного подогнанного направления —
`1.25(1−f)F0/n_вид = 3.29e-5`, и она **не зависит ни от q, ни от силы сигнала**.
